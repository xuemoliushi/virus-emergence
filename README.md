# 病毒涌现 · 开发纪念

这是我在 TapTap Maker 中制作的游戏《病毒涌现》的个人纪念备份。

本仓库保存 **2026 年 11 月 3 日**本地工作目录中的版本，包含当时未提交到原仓库的正式素材和文档。游戏配置版本：**1.0.11**。

## 保存内容

- `scripts/`：Lua 游戏源码与素材处理脚本，入口为 `scripts/main.lua`。
- `assets/`：游戏图片、音频、正式结局视频和宣传素材，保留资源 `.meta` 与素材来源记录。
- `docs/`：设计及开发文档、宣传图、素材使用声明等。
- `tests/`：测试代码。
- `UI/`、`按钮/`、`2026-10-14_鸟群坠落/`：项目中保留的界面与美术工作文件。
- `.project/`：现有项目配置与封面资源。
- 根目录启动脚本及 `local-preview/`：原有本地试玩辅助工具。
- `BACKUP-MANIFEST.json`：备份文件清单、大小、SHA-256 校验值和来源版本编号。

## 运行说明

这是 **UrhoX Lua / TapTap Maker 工程**，不是可直接双击运行的独立发行版，也不是 GitHub Pages 网页。需要另行准备匹配的 Maker 开发环境、UrhoX 运行时及引擎内置库。

原有启动工具依赖本机 Maker 安装和 `.maker-mcp/config.json`，该本机绑定文件未上传，因此在新电脑上需要先配置开发环境及项目绑定。不要直接沿用原项目的账户凭据。可参考 `本地试玩说明.md` 了解原本的试玩方式。

## 备份范围
