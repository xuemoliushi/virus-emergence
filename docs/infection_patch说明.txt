局部感染色斑 infection_patch —— 交付说明
================================================================

一、这一套是干什么的
  用来**替代**"整个细胞从红渐变到感染色"的做法。
  只在一个**附着点**附近贴一小块半透明的琥珀橙斑，向外衰减淡掉，
  再往细胞内部渗几颗小暖粒。程序从附着点开始，逐步放大 / 叠加 2~3 块，
  做出"感染从一个点慢慢洇开"的过程。
  ⚠ 不要拿一整张"已经完全变橙的细胞"来切图替换 —— 那是错的。

二、文件
  infection_patch.png              色斑本体        300x300 四边全透明
  infection_scene_alpha.png        透明蒙版大图    1600x1600（背景全透明）
  infection_scene_dark.png         暗底大图        1600x1600（同样构图，方便观看）
  infection_patch_meta.json        摆放参数（见下）
  预览/                            验收图（边界检查 / 生长序列 / 尺寸 / 透明区校验）

三、坐标约定（很重要）
  画布 300x300，**画布中心 (150,150) = 附着点**（色斑最密的地方）。
      +x = 沿细胞膜扩散的方向
      +y = 朝细胞**内部**（那几颗小暖粒在这个方向上）
  本素材前景 128x190，**竖着比横着长**（y 方向更长），
  所以按上面的约定摆，色斑会**更多地往细胞里面洇**，横向扩散少一点 —— 这是有意的。
  想要"沿膜横向铺开"的观感，把 sprite 再转 90° 即可。

四、摆放规则（程序照这个做）
  1) 找到病毒与细胞的接触点 P 和该点的外向单位法线 n。
     把 sprite 的 +y 转到 −n（即朝内）：rot = atan2(n.x, -n.y)（度）。
     ⚠ 交给 PIL rotate() 时要取负号（PIL 是视觉逆时针，而数组坐标 y 向下）。
  2) sprite 画布中心对齐 P，**不要**再额外偏移；锚点就是中心。
  3) 逐级叠加（meta.json 的 stack，scale 是相对本素材 300px 的倍数）：
       1/3  额外旋转 +0°  缩放 0.55
       2/3  额外旋转 +25°  缩放 0.78
       3/3  额外旋转 -20°  缩放 1.00
     额外旋转让几块斑的边缘互相错开，不至于完全重合看出一个形状。
  4) 尺寸怎么定：**可见宽度 = 精灵画布尺寸 × 0.427**
     （本素材前景只有 128px 宽，剩下都是透明边）。
     反推：精灵缩放 = 目标可见宽度 / 128
        想让屏幕上色斑可见宽度 60px → 缩放 60/128 = 0.47，画布画成 141px。
     ★ 本版已按客户「参考病毒比例大小，增大感染部分」上调（原为 230px）：
        第 3 块可见宽 **366px** = 细胞前景宽度的 45%（= 3.0 个病毒宽）
        细胞 240px 时 → 可见宽约 109px
                      → 精灵缩放 0.85，画布画成 255px
        尺寸梯子（1.0x / 1.3x / 1.6x / 2.0x；每档都有「单个附着点」和「7 个附着点」两种观感）：
        预览/scale_ladder.png —— 要更大或更小，直接指一个档位。
  5) ⚠ **必须按细胞轮廓裁剪**：采样时乘上同位置的细胞 alpha。
         patch_alpha_final = patch_alpha × cell_alpha
     不裁的话，斑会糊到细胞轮廓外的近黑背景上，半透明暖色压在黑底上会变成脏褐斑。
     参考实现：tools_preview_infection_patch_v3.py / tools_render_infection_scene.py 的 over(..., clip_a=cell_alpha)
  6) 叠放顺序：细胞 → 色斑（可多块，由小到大）→ attachment_glint → 病毒本体。

五、这一张大图（infection_scene_*）是怎么摆的
  细胞前景 807x878
  接触点画布坐标 (1005,1186)　外法线 (+0.469,+0.883)
  病毒目标宽 121px = 细胞前景 807px × 0.15
    （**比例是恒定的**：客户参考图里的 156px 也是「该图细胞前景宽 × 0.15」，
      不是同一个绝对像素数 —— 换细胞尺寸要按比例重算）
    色斑 1/3  额外旋转 +0°  缩放 0.55  屏幕画布 472px（可见约 201px）
    色斑 2/3  额外旋转 +25°  缩放 0.78  屏幕画布 669px（可见约 285px）
    色斑 3/3  额外旋转 -20°  缩放 1.00  屏幕画布 858px（可见约 366px）
  三块全部按细胞轮廓裁剪。
  ※ 这些数字由 tools_render_infection_scene.py 落到 output/_work/infection_scene_log.json，
    打包时直接读 —— **不是手写的**。

六、验收结论（都是本脚本现场量出来的）
  · 300x300，四角 alpha = [0, 0, 0, 0]（全透明）✓
  · 透明区残留 RGB 最大值 = 0（透明区颜色干净，没有溢色）✓
  · 前景包围盒 (96, 94, 223, 283)  128x190  覆盖率 12.07% ✓
  · 半透明像素 12.071%（与审计口径一致：0<alpha<255；浓淡过渡真实，不是一块死板的实心）✓
  · alpha 取值 253 种（连续渐变）✓
  · 中心像素 alpha = 251（中心就是最密处 = 附着点）✓
  · 环检测：实心区补洞只多出 309px / 实心 9587px
    （3.2%，远小于 55%，说明**不是**一个圈）✓
  · 最密处（alpha 前 12%）的重心距画布中心仅 0.7px —— 附着点就压在中心 ✓
    （整体质心偏 27.4px，是"向内衰减"造成的，正常）
  · alpha 形态：直通（非预乘）✓
  · 透明蒙版审计：infection_patch.png 与 infection_scene_alpha.png **2/2 合规** ✓
  · 大图 1600x1600 四角 alpha = 0，透明区占 81.3%、透明区残留 RGB = 0 ✓

七、这一包怎么来的 / 怎么再生成
  · 候选：tools_gen_image_batch.py 跑 output/_work/_p_infection_patch_v3.txt
          → output/_work/patch_v3/patch_A..D.png（选中的是 C）
  · 定稿：tools_finalize_infection_patch_v3.py
          （定原点 → 旋转到方形大画布避免切角 → 径向衰减 → 内部暖粒 → 按原点裁 300px）
  · 预览：tools_preview_infection_patch_v3.py
  · 大图：tools_render_infection_scene.py --canvas 1600 --angle 62 --patch-vis 366
  · 透明区校验：tools_preview_infection_scene.py
  · 打包（本目录）：tools_pack_infection_patch.py
  源文件常驻 art/细胞分层/（拆层流水线也用它），本目录是**交付快照**；
  改了源文件后重跑一次打包脚本即可同步。
