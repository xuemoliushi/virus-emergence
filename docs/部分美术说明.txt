  ★ 关于"平涂"指标（重要，别误判为缺陷）
    这一版的粗色桶集中度明显低于上一版平涂分层风格（那版 alpha>0 前6桶 96.7%）。
    原因是**旧版风格本身就是软调**：球体带明暗渐变、左上水彩高光、表面斑驳颗粒，
    不是三块纯色平涂。对照基准（卡通家具 93.3%、3D 89.1%）它落在偏软一侧。
    alpha=255（硬边像素）口径下前 6 桶 84~95%，主体仍是单一橙色调，没有杂色。
    → 这是**用户指定的风格特征**，不是画坏了；游戏内既有精灵
      `art/表面吸附病毒/virus_attached_particle.png` 也是这一版派生，风格自洽。

  配色（virus_master 实读）：
    主体（核心/中环）中位色 (252,125,35) / (252,124,34)，外缘压暗到 (192,85,31)
    alpha=255 口径前 3 桶：(224,96,32) 45% / (224,128,32) 15% / (224,160,64) 8%
  形态：暖橙球体 + 约 13 根带球头的棍棒冠（等长、均匀分布）+ 左上单个水彩高光。
  32² 下仍可辨（暗底预览右端 32/16 格）。

  ★ 主体 alpha 拉满（2026-10-08 加的一步）
    旧 AI 原图整个身体盖着一层 alpha 241~254 的薄雾（真正 alpha==255 的像素占 0%），
    与本项目约定「病毒本体硬边、只有接触亮点柔边」不一致，也让审计一直报
    「半透明像素占比 55%」。做法：腐蚀 3 次取内核 ∩ (alpha >= 247) → 255，
    轮廓那一圈柔边与高光晕保留。实测 552750px 被拉满，4 种底色下可见区最大
    差异 8.00/255（≈3%），断言写在脚本里（>8/255 就报错）。
    注意游戏内精灵 virus_attached_particle.png 本来就是 100% 硬边，拉满后**更接近**它。
    ⚠ 不能"腐蚀出内核就整块写 255"：主体内混有 alpha<100 甚至 alpha=1 但 RGB 很亮
      的像素，一律写 255 会当场点出亮斑（首版炸出 254/255 的可见差异，被断言拦下）。

       · 膜片 = art/细胞分层/cell_membrane.png 抠一段弧（铁律：同一对象多状态必须
         同一母版局部修改）—— 落点自动选在 24°（外缘起伏仅 5px），弧半张角 26°

     实测几何：
       芽体外接宽 121.0px（= 0.15 × 807，含棍棒冠）  暖橙核心 119.4px
       球体内切直径 77.2px（刺突不计入）  膜带厚 36px  带/芽 = 0.30
       半透明像素占比 2.6%
     叠放参数（output/_work/budding_tip_prog_meta.json）：

       rotate_deg +24°  cell_center (626.0, 626.5)  cell_canvas 1254²
       crop_window [327, 154, 924, 415]

     再贴。★ 只有落在与细胞膜同半径的位置才是无缝的（膜片就是那里抠下来的）。

    用户要的是"出芽过程图"：AI 直出钉不住中间态比例（同"主角必大"偏见），
    而膜隆起/球半径/颈半宽本质就是几个几何量 → 交程序。
  素材与口径：
    · 膜片 = output/_work/budding_membrane_wedge.png（就是出芽点抠下来、未上接触色的那块膜弧）
    · 芽体 = art/virus/virus_master.png（实测球体外接比 250/392 = 0.639 → 满尺寸球半径 38.7px）
    · 芽体外接宽 121px = VIRUS_RATIO × 807；落点/细胞中心/裁窗 = budding_tip_prog_meta.json
    · 六帧**公共画布 597×261**，与出芽点同尺寸 → 可直接当作出芽点的动画序列用

      "露出膜面" = 轴线附近暖橙顶端到膜面的高度，逐帧实测；阶段 6 是刺突外接缘离膜面 6px。
      隆起实测值比设定值大 ~1px，是 alpha>16 阈值多算了柔边，属口径差不是误差。）

  ★★ 关键：前 3 阶段要读成"**从膜里面顶出来**"，靠的是叠放次序不是画画
    · 无柄阶段（1/2/3）**先画芽体、再叠膜**：芽体裁到"膜面 − 3px"（INSIDE_EMBED），
      多出的 3px 被膜的不透明带压住 → 芽体下半被膜遮住，视觉上就是"从膜内/膜后顶出来"。
      若反过来（芽体叠在膜上层），读起来就变成"贴在膜外表面上长大"——这是第一版的问题。
    · 实测露出高度逐帧递增 21 → 41 → 84 → 100 → 111 → 125 px，是"出来多少"的进度尺；
      脚本对 inside 阶段断言 0 < 露出 < 2×芽体外接宽。
    · 双模型交叉判读确认：第 1/2/3 幅球体与膜交界处**存在遮挡关系**（被膜边缘截住），
      不是"球悬浮在膜上方、彼此不遮挡"。

  构造要点：
    · 膜隆起 = 极坐标逆映射径向拉伸，内缘钉住、外缘外扩 h·exp(−τ²/2σ²)，σ=46px
      （切向 ±46px ≈ 弧上 ±9°，落在膜弧平坦段内，不会碰到两端的卷曲）
    · 颈部 = 沙漏型宽度剖面 w(t) = (1−t)·颈根 + t·颈肩 − dip·sin(πt)（t = 沿柄归一化位置）。
      颈肩半宽取 0.38 × 芽体外接半径——这个值不是随手取的：球体在 0.80·r_sph 处横切，
      切面半宽 = √(1−0.8²)·r_sph = 0.6·r_sph ≈ 0.38×外接半径，所以柄壁与球体剪影**等宽相接**，
      轮廓连续，也不会凸出一圈"领口"。
    · 颈部材质采样自膜带**中—外层**（t_src = 0.42~0.72，实测 (250,105,105)~(252,140,142) 亮珊瑚红）。
      不采内层（t<0.3 是深红 (212,48,54)，柄会看成"暗洞"）、不采内膜柔边（alpha≈46 会透底）。
    · 叠放顺序：无柄阶段 芽体 → 膜；有柄阶段 膜 → 颈 → 芽体（颈顶多伸出 2.5px，被芽体压住；
      颈根扎进膜外缘 2px）；脱离阶段 膜 → 芽体。
    · 接触处按 V1「红膜**局部**加琥珀橙暖黄」上色，参数与出芽点同一套（半径 1.55×芽体外接半径）。
    · 阶段 6 隆起取 −3px（断裂后膜面回缩）、接触光强降到 0.40 → 留一道暖色残痕。

  ★★ 本轮修掉的两个真 bug（都是"数字看着对、图却错"的类型，已各加一条断言防复发）
    (1) bump_warp 的取心没换算成**窗口局部坐标** —— 传进去的是细胞中心，而数组是裁窗子图，
        极坐标映射退化成恒等变换 → **膜完全没有隆起**。实测证据：错误取心下输出 13763px
        ≈ 源 13700px（无变化），用局部原点才是 15191px（真拉伸）。
        当时肉眼看"膜像有隆起"全是琥珀接触光的错觉。
        → 现在每次隆起后**回量**膜外缘位移，与设定值差 >2px 直接抛错。
    (2) 膜带半径用了 meta 的**弧段统计值** 304.1，而该角度膜片真实外缘只有 295.75（差 8.4px，
        因为统计值把稀疏游离颗粒的极值算进来了）→ 颈部材质采样在靠近球体的一端落到膜带
        **之外**、采到 alpha=0：表现是球—颈交界一道 **1px 透明裂缝**，另加一段 alpha=46 的
        "鬼影颈"（半透明鬼影条，肉眼在缩略图上会当成阴影）。
        → 现在膜带一律**在膜片上现量**（a>128 的径向内外缘），并逐帧断言
          「轴线列上：相连阶段只能有 1 段 alpha>40，脱离阶段必须 2 段」——有裂缝立刻变 2 段。

  校验记录：
    · 跨帧"膜同源"：六帧在**距接触点 280px 以外逐像素完全一致**（差异 0 px）；96~184px 环带的
      少量差异全部来自隆起尾部的边缘位移（差异像素最大距离 184.4px ≈ 4σ）→ 符合
      「同一对象多状态必须同一母版局部修改」。
    · 轴线列连续段：阶段 1~5 各 1 段（相连无缝）、阶段 6 分 2 段（真断开 10px 空隙）。
    · 露出高度逐帧递增 21/41/84/100/111/125px（脚本断言 inside 阶段落在 0~2×外接宽内）。
    · 双模型交叉判读（gpt-5.6-sol / gpt-6-astra）五问全一致：1/2 幅像"从膜内/后面顶出来、
      下半被膜遮住"、露出量 1→6 递增、4/5 有柄且 5 更细、6 已断开见空隙、1/2/3 幅交界
      **存在遮挡关系**；另确认交界无不自然平直切口。
    · 透明蒙版审计 6/6 合规；bleed 后残留 RGB 全部归 0。
