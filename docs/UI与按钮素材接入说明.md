# UI 与按钮素材接入说明

2026-10-14。本轮按用户确认更新界面外观并部分重排布局，素材来自桌面「按钮」「UI」两个目录及《UI与按钮素材用途说明》。不接入结局视频播放器。

## 素材与外观

原始 51 张 PNG 已原样导入 `assets/image/ui/frames`（24 张）与 `assets/image/ui/icons`（27 张）。`mapping.json` 记录来源文件、SHA-256 和显示副本，原文件未重绘。视频外框保留为后续素材。

16 张可伸缩底框／控件生成等比例缩小副本放在 `scaled/`，让边角尺寸适合现有逻辑像素和触摸区域。九宫格按本地引擎实际读取的 `{top,right,bottom,left}` 数字数组传参，所有正文、快捷键、群编号、数量、成本和冷却仍由程序绘制。原生 UI 组件继续处理点击、拖动、滚动、数值、回调和暂停；皮肤位于 `scripts/UI/AssetTheme.lua`，没有修改引擎参考库。

界面配色统一为深棕、铜金边、暖色图标与浅色正文。悬停、按下、禁用和当前群状态通过明暗、文字和描边区分。既有中文字体、DPR、安全区与玩家界面缩放保持有效。

## 布局与入口

- 主菜单：主要按钮与普通菜单按钮分层，按 5:1／6:1 原素材比例设置宽高；标题增加装饰，仍使用动态文字和当前背景。
- HUD：左上任务／场景信息、右上病程／数量统计、下方基础操作与群选择。四个基础按钮使用图标，按可用宽度换行；详细统计用实际按钮展开，数据继续实时刷新。
- 快捷技能：与基础操作区对齐，保留获得后才显示的冲刺与诱饵。名称、冷却、投入和失败原因分行；仅保留一处可见功能菜单入口，避免重复入口挤占空间。
- 功能菜单：动态技能图标跟随真实能力和子菜单变化；六个数字键提示独立显示，列表滚动，返回／关闭固定在底部。窄矮窗口提高菜单可用高度。
- 被动能力：六项图标只在获得后显示，不新增点击技能；原状态文字保留，已消耗的断尾状态降低图标亮度。
- 小地图：替换外框，内部地图和镜头框继续程序绘制。与快捷操作错开；逻辑窗口高度不足 600 时暂时隐藏，避免遮挡操作区域。
- 摇杆：底盘与可移动摇杆帽使用独立素材，保留原有手指捕获和取消逻辑，尺寸提高到 120／45 逻辑像素。
- 设定：统一大面板、音量轨道／滑块、下拉框／列表、动态背景开关和按钮。教程跳过勾选、重置按钮及其状态文字一并更新；重置仍自动取消跳过。
- 教程：统一提示卡、继续按钮、收集方向文字底框；实际边缘三角、焦点标记和教程事件流程保留。
- 选卡：外层面板和获取／继续按钮统一，保留原有 18 张卡图与同步音效渐显。
- 结算：统一外框、标题装饰、返回与重开按钮；视频播放按用户确认留待后续。
