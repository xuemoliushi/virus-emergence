感染色块 infection_block —— 交付说明
================================================================

一、这是什么
  把 infection_patch.png 里**单独扣一块**出来（透明蒙版）：
    · 只留**一块** —— 主体是最大的连通块，另外 251 个碎粒（共 1523px）全丢掉；
      主体内部的 277px 针孔封上（只封洞，外轮廓一点不动，面积只 +3.0%）
    · 只留**一个颜色** —— 把原来的浓淡纹理换成**单一感染色**（平涂），
      边缘浓淡（alpha）保留，所以还是"向外衰减"的，不是硬贴片。
  用途：比色斑更轻量、更平滑的感染表现；也方便引擎直接给 sprite 染色 / 加自己的渐变光。

二、文件（三选一，推荐第一个）
  infection_block_flat.png     只主体 + 平涂 #E36804 + 原浓淡        ← 推荐
  infection_block_only.png     只主体 + 原素材颜色（想丢碎粒但保留纹理时用）
  infection_block_solid.png    只主体 + 平涂 + 实心化（引擎自己上渐变/染色时用）
  infection_block_meta.json    参数 + 色板（程序读这个）
  预览/                        验收图

三、感染色
  平涂色 = 原色斑的「核心中位数色」= RGB(227, 104, 4) = #E36804
  三个候选（**都从原素材现场量出来的**，不是挑的）：
      核心中位数   #E36804   RGB(227, 104, 4)   ← 平涂采用这个
      最密处       #D23401   RGB(210, 52, 1)
      alpha 加权均 #E37818   RGB(227, 120, 24)
  ★ 色阶关系（色块正好卡在中间，这就是"正在被感染"的中间态色）：
      健康细胞膜 #A44449 RGB(164,68,73)  →  **感染色块 #E36804**  →  感染细胞黄 #D5A524 RGB(213,165,36)
  想换色：python tools_make_infection_color_block.py --flat "R,G,B"
         python tools_make_infection_color_block.py --zero     # 透明区 RGB 清零（默认是颜色外扩）

四、坐标与摆放 —— 和 infection_patch.png **完全同一套**，可直接替换
  300x300，画布中心 = 附着点（和 infection_patch.png 完全同一套坐标，可直接替换）
  +x = 沿细胞膜扩散方向；+y = 朝细胞内部
  摆放公式、裁剪要求、推荐尺寸全部沿用色斑那一套，见 art/局部感染色斑/说明.txt
  ⚠ 同样**必须按细胞轮廓裁剪**（乘同位置细胞 alpha），否则会糊到细胞外的背景上
  推荐尺寸（和色斑一致，见 预览/参考_尺寸梯子.png）：
      366px 可见宽 = 细胞前景宽度的 45%（= 3.0 个病毒宽）
      细胞 240px 时 → 可见约 109px
                    → 精灵缩放 0.85，画布 255px

五、实测（本脚本现场量）
  文件                          可见像素   不同 RGB 值   包围盒               半透明      alpha 取值
  infection_block_flat.png         9618           1   (97, 104, 202, 244)   10.687%      253
  infection_block_only.png         9618        7434   (97, 104, 202, 244)   10.687%      253
  infection_block_solid.png        7000           1   (99, 105, 200, 241)    3.776%       89
  · flat / solid 的「不同 RGB 值 = 1」= 真的只有一个颜色，浓淡全靠 alpha ✓
  · 三件四角 alpha 全 0、透明区颜色外扩无错色、alpha 直通（非预乘）✓
  · 透明蒙版审计 **3/3 合规** ✓

六、已知特性（不是 bug）
  · 边缘是原素材的**像素台阶**（原 AI 图就是这样）。平涂之后台阶比带纹理时更显眼。
    实机尺寸（可见宽约 108px）下基本看不出来；如果你要在很大的尺寸下用，
    可以对 alpha 做一次 1px 高斯再存。
  · 透明区做了**颜色外扩**（最近可见像素），缩放 / 双线性过滤 / mipmap 不会拉出黑边。
    要 0 填充加 --zero 重跑。

七、这一包怎么来的 / 怎么再生成
  · 生成：tools_make_infection_color_block.py   （连通块 → 只留最大 → 封针孔 → 平涂/实心化 → 颜色外扩）
  · 验收图：tools_preview_infection_block.py    → output/preview/infection_block_preview.png
  · 打包（本目录）：tools_pack_infection_block.py
  源素材 art/细胞分层/infection_patch.png（**没动过**），本目录是交付快照。
