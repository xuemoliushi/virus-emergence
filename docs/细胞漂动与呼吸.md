# 细胞漂动与呼吸（2026-10-17）

已按用户后续确认采用纯图像变换。普通细胞在原位附近缓慢漂动并轻微拉伸；巨噬细胞、T 细胞只拉伸，不新增随机平移。之前的病毒视觉碰撞求解器和轮廓保持原样，玩法坐标、半径、感染与免疫判定均不变。

## 表现幅度与衔接

- 按用户对“像抖动”的反馈，改为约 29 秒一轮的连续弧线，叠加较弱的约 48 秒方向变化。两个轴沿同一条弧线缓慢游移，不再各自较快往复。
- 按用户允许少量病毒图像与细胞壁重叠的取舍，微增漂移幅度：横轴最多为自身半径的 7.5%，纵轴 6%；半径 0.4 米时分别最多 0.030、0.024 米。轨迹始终限制在原位附近，不会长期走离原位。
- 呼吸主周期从约 4 秒放慢到约 7 秒，横轴最多偏离 1.7%，纵轴最多偏离 1.3%，主拉伸方向相反，另有小幅共同胀缩。实体各自有固定相位，避免同步起伏。
- 细胞主体、膜、液泡、感染色斑、附着病毒和膜芽共用变换。出芽交接的起点随膜拉伸，终点回到释放病毒的世界位置，避免把漂动误带入释放后的坐标。
- 免疫细胞只对本体、内部光效及矢量回退应用呼吸变换；警戒圈、范围和文字保持原尺寸。已有移动插值与碰撞位移正常保留。
- 暂停时动画时钟停止；死亡膜保留死亡前姿态，沿原有消退流程显示；切换世界及销毁视图会清理缓存。
- 视觉碰撞边界保持静态，游离病毒不会因细胞呼吸而被推动。由于图像有微小偏移/缩放，边缘可能有少量视觉穿入或空隙，这是本次优先降低开销的明确取舍。

## 性能方式与测量

新增模块 `scripts/Game/Views/CellVitality.lua` 只维护显示缓存。每次更新共用六次三角函数运算，再用各实体缓存系数组合出动作；不逐帧生成随机数。视口外的缓存会移除，更新仍仅线性遍历实体。没有新增碰撞查询、物理体、纹理或绘制图元。普通细胞复用原有缩放调用，免疫本体增加少量 NanoVG 变换调用。

本次参数修正后的本机 Lua 5.4 CPU 微基准：960 个普通细胞、30 个免疫细胞全部参与更新，预热后测量 500 次，中位 0.177 毫秒，P95 0.191 毫秒。只测新增动画更新，不包括渲染、GPU 和整机帧率，数字应作为量级参考。仍共用六次三角函数，不增加碰撞开销。
