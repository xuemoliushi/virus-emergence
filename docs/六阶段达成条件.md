# 六阶段达成条件

2026-10-20：在《阶段任务与卡牌获取方案（15—20分钟）》首轮规则上改为“硬性阶段计数”：每个阶段只认本阶段内起步并完成的成果，杜绝选卡后连续完成。数值集中在 `scripts/Core/Config.lua` 的 `Config.Evolution`。

### 硬性阶段计数（2026-10-20）

- 每个细胞记录本轮接触的起步序号 `contactSerial`（exposure 从 0 变为正值时取号，接触中断、exposure 归零后清除）。进入阶段时记录 `world.contactSerial` 为边界。
- 只有起步序号大于本阶段边界、并在本阶段完成感染的细胞计入。上一阶段已开始感染、在选卡后才完成的细胞**不计入任何阶段**，界面提示“上一阶段已开始感染的细胞不计入本阶段”。
- 阶段三不再统计“当前同时产毒”这一存量，改为“建立3个新的产毒节点”：本阶段新感染的3个细胞各完成首次释放。旧节点、开局节点即使正在产毒也不计，因此不能在进入阶段的瞬间达成。
- 阶段二内部的“先回收、再感染”仍以回收时的感染序号为界；阶段边界本身使用接触起步序号。终局扩张同样采用接触起步边界。

| 阶段 | 任务 | 判定 |
| --- | --- | --- |
| 1 首次产出 | 感染1个新细胞，等待它释放病毒。 | 本阶段一个新细胞成功进入LATENT，并真实释放过病毒。开局节点不计，释放后死亡不撤销事实。 |
| 2 回收与感染 | 先吸附节点释放的病毒，再感染2个新细胞。 | 本阶段通过E基础吸附或主动离散回收，实际吸入至少1颗感染节点产物；以首次有效吸入时的感染序号为界，再感染2个本阶段起步的细胞。 |
| 3 多点产毒 | 建立3个新的产毒节点。 | 本阶段起步并完成感染的3个细胞各完成首次释放；释放后死亡不撤销。旧节点与开局节点不计。 |
| 4 继续扩张 | 再建立4个感染节点。 | 进入阶段后起步并完成感染的4个不同细胞。 |
| 5 扩大感染 | 再感染8个新细胞。 | 进入阶段后起步并完成感染的8个不同细胞。 |
| 6 最后进化 | 再感染12个新细胞，获得最后一张进化卡。 | 进入阶段后起步并完成感染的12个不同细胞；没有病理比例和维持计时门槛。 |
| 终局，不再发卡 | 再感染4个新细胞，让炎症或组织损伤达到失控。 | 关闭第六张卡说明后起步并完成的4个感染，并获得炎症、损伤或连续呼吸衰竭任一胜利资格。已取得的资格保留。 |

成功感染的细胞就是感染节点。仅接触或进入EXPOSED不计；所有真实感染来源均有效，累计成果不因耗竭或死亡倒扣，不要求指定卡牌、分群、区域或免疫攻击事件。保留整局累计16个感染的兼容底线，不作为额外界面任务。

## 边界与回收来源

每个感染细胞保存成功感染序号，首次真实释放另存永久事实。阶段切换发生在确认卡牌并关闭警戒说明后，此刻记录累计感染边界。同一步内选卡前产生的全部感染均属于旧阶段；旧事件延后消费或重放不计下一阶段。每阶段只触发一次三选一。

阶段二的回收事件保存游离实体ID、节点产物来源、主动方式和吸入当时的感染基线。上一阶段释放的产物可在本阶段主动回收。被动吸收、空按、诱饵、拖尾、合并播种、接力小队回收与节点接管不计。首次有效回收之前完成的感染仍保留整局成果，但不计后续两次新增。重复事件不增加回收数量。

教程中的有效感染和首次产出正常累计，教程结束后才展示选卡。选卡、说明和其他暂停不推进模拟。终局仍可能灭团；病理资格不能跳过六次选卡和最后扩张。若连续呼吸衰竭先达标，任务改为“再感染4个新细胞，完成最后扩张”。

## 界面和体验记录

任务区显示当前任务、分别计量的进度、行动提示和奖励。感染成功提供短提示，依据免疫威胁、病毒供给与接触状态调整建议。手机默认显示正文和进度，详情中展示行动提示和奖励；节点统计已移除重复的任务提示控件。

目标局长配置为900／1200秒。基础感染、28秒潜伏和18秒批次间隔保持原值，没有最短发卡间隔。`[FlowMetrics]`记录开始、进度、完成、发卡、确认、阶段进入、终局、病理资格和结算，另按5秒模拟时间采样场面。每条包含种子、累计感染、实际吸收、有效任务回收、产毒数、清除／失活损失和卡牌数量；`card`行记录卡牌ID。

## 2026-10-20：目标耗尽与节点丢失的处理

上表保留正常情况下的原目标。可感染细胞只包括全图的 HEALTHY 和 EXPOSED，潜伏、产毒、耗竭、死亡细胞均不能重复感染。以下边界规则防止任务要求不存在的目标，任务正文与详情会明确显示调整原因。

- 阶段1：首次释放前节点被杀，且仍有健康细胞时，提示重新感染，仍须真实首次产出。如果全图可感染细胞和本阶段仍可首次产出的节点都已耗尽，则结算已经真实完成的新感染，不伪造释放、不复活细胞。
- 阶段2：没有存活产毒来源，也没有可回收节点产物时，切换为从阶段进入时起感染两个新细胞重建网络；分支保持到本阶段结束。仍有死节点产物或耗竭节点可以释放时，保留主动回收目标。正常回收与重建分支中的新增感染目标，均不超过对应基线后已完成的感染数加全图剩余可感染数量。
- 阶段3：可成为 PRODUCTIVE 的细胞总数为 HEALTHY、EXPOSED、LATENT、PRODUCTIVE 之和。只有这个上限不足3时才降低同时产毒目标；耗竭、死亡节点不冒充正在产毒节点。如果上限为0，则明确提示目标耗尽并结算。正常可达情况下仍要求3个同时产毒。
- 阶段4、5、6及终局：新增感染目标为配置数量与“对应基线后的真实新增感染数＋全图剩余可感染数量”的较小值。已完成感染不会倒扣；全部目标耗尽时允许结算该阶段，六轮选卡各只发放一次。
- 阶段达标后冻结目标与完成状态，后续节点死亡不撤销成果。终局仍须完成六次正式选卡并取得病理资格；没有新细胞可感染不等于自动胜利。整局16个感染的兼容底线也不超过当前地图仍可实现的累计感染上限。

`tests/stage_softlock_regression.py` 验证剩余0/1/2个目标、节点被杀、阶段切换、最终病理条件和全图目标耗尽后的六轮选卡。`--production-seed` 使用正式v5地图的960个真实细胞；感染与死亡由明确标注的夹具调用真实方法构造，不代表自然游玩或手机画面验收。

`experience`为可操控期间实际帧时间加选卡与警戒说明时间，教程、其他暂停、菜单和结局影片不计；`active`、`choice`、`tutorial`、`pause`分别记录。`t`为模拟时间，卡顿丢弃的模拟步不会冒充有效战斗推进。保留失败局和`debug`标记，夹具或测试获取不作为正式玩家样本。
