# 连续组织地图与随机种子验收

2026-10-12，最终生成版本 **3**。按用户后续要求停止录屏，改用正常入口游玩、截图、数据快照和日志验证。

## 实现结果

真实世界从 26×32 米扩大到 **78×96 米**，保留 5 个连续组织区域、5 条连接通道。默认 **216 个细胞**，上呼吸道开局 30 个病毒、2 个免疫单位；免疫招募与病毒释放继续按原规则推进。世界尺寸扩大 9 倍面积，细胞数量为原来的 3 倍，兼顾探索距离和现有模拟性能。

第一版大地图的 108 个细胞主要集中在区域中心。原因是中心向外的候选序列达到总数后提前停止，以及圆形候选环无法覆盖宽扁椭圆。版本 3 改为：

1. 三个可选出生点各保留 3 个近距离健康目标，其他细胞避让出生安全范围。
2. 沿通道弧长间隔 4 米放置路线目标。
3. 在每个区域的完整椭圆范围生成带种子抖动的分层候选点；保留八个方向的边缘目标。
4. 按区域面积和现有疏密设计分配独立配额。左支气管比右支气管密集。
5. 在各自配额内优先填补离现有细胞最远的空隙。候选相位、位置和优先级由种子决定。
6. 候选耗尽时使用有限安全格点，仍按最远空隙优先补齐。不能满足配置约束时明确报错，不生成重叠或封路的无效地图。

默认种子的区域细胞数量为 **26 / 26 / 66 / 43 / 55**；边缘细胞数量为 **14 / 16 / 33 / 19 / 26**。细胞不是移动墙体，连通性依据原有椭圆、胶囊通道和精确扫掠移动检查，不虚构细胞阻挡。

## 复现地图

在 `scripts/Core/Config.lua` 的 `Config.Gameplay` 中设置：

```lua
width = 78, height = 96, cellCount = 216,
mapSeed = 314159, mapGenerationVersion = 3,
mapRegionCount = 5, mapRegionSpacing = 3.0, mapDensity = 1.0,
mapEdgeCoverage = 0.87, mapCoverageSampleSpacing = 2.0,
mapSpawnSafeRadius = 2.0, mapChannelWidth = 3.0,
mapRouteTargetSpacing = 4, mapCellGap = .16,
```

修改后重新构建并新开一局。相同版本、种子与配置复现相同区域、通道、稳定 ID、细胞类型、位置、半径、相位、旋转和初始属性。默认种子固定，便于检查本次修复。可指定其他整数或文本，如 `mapSeed = "组织探索"`。设为 `nil` 时，每次创建新世界只选取一次实际种子；HUD 与 `[Map]` 日志显示该值，用它可以复现该局布局。更新、缩放、窗口调整、镜头移动不生成新种子。

PRNG 使用乘数 48271、模数 2147483647；乘积低于 2^53。归一化结果范围 **1..2147483646**。数值种子取 floor 后取模；UTF-8 文本按字节使用乘数 131 的确定性多项式转换。拓扑、细胞布局、外观使用独立显式流，不调用全局 `math.randomseed` 或战斗 `_rng`。布局生成遍历采用固定顺序。

布局与初始状态复现已经验证；**不承诺整局战斗结果完全复现**，仍保留原有模拟随机数和输入时序。版本 2 用相同旧配置仍返回旧快照 SHA256 `bdccf26886342de1eda6b35d42fea58864a6f7d8e0779151ea216a8aa47166d7`。

`417e4eddafeb5372acda57595bb370497e8df55d71cbb2bf05a5b22ca9547b03`

## 摄像机、导航与性能

保留原操作方式、镜头平滑跟随、切群生命周期和缩放。边界计算考虑实际 HUD 让出的视口及镜头垂直偏移；可见范围大于世界某轴时，该轴按视口中心居中。输入反变换、细胞层、附着病毒、接触亮斑、感染色斑共用原 `CellView` 转换。小地图通过同一转换显示视野框，HUD 固定于屏幕。

保留现有空间网格、精确接触条件和带边距绘制剔除。离屏细胞继续感染、潜伏、释放，免疫继续更新。小地图只画形状和标记；细胞蒙版缓存保留原默认 72、硬上限 96 的资源限制及 Destroy 生命周期。生成阶段缓存候选点到现有细胞的最小距离，只在放置新细胞后更新，避免重复全部邻近查询。

胜负依据原炎症 180、损伤 110、呼吸衰竭和六阶段任务，不要求感染全图细胞；未调整阈值、阶段任务或其他战斗平衡数值。细胞数量增加提供更多探索与传播目标，但完整一局时长仍需要后续平衡游玩观察。

## 验证与构建证据

证据位于 `validation/seeded-map/`。

- `generation.json`、`seed-314159.snapshot.txt`：10 个不同种子，每个重复生成并比较完整有序初始数据；不同种子哈希均不同。检查出生安全、细胞间距、真实世界边界、最大 1.35 米群体的区域可达性、全部细胞可达性以及全局/模拟随机流隔离。10 种子后备次数均为 0。
- `coverage.json`：各区域八向边缘均有目标；按可移动区域每米采样，默认种子最大最近细胞距离从 **12.81 米降至 4.53 米**，10 种子均小于 **4.7 米**。边缘不是不可移动的矩形背景角落；背景角落和组织之间的隔离空隙仍保留。
- `coverage-comparison.png`：同种子版本 2 / 3 的真实地图数据俯视对比，非游戏截图。
- `camera.json`：125 组常规、横竖小屏、缩放、四边和视野超尺寸检查通过，使用实际 CellView 双向转换。
- `regressions.json`：最终 **15 组回归全部通过**，覆盖接触、感染转换、ReleasedVirus、渲染拆层、异步纹理、增长、自主群、进化、菜单、观察与性能。
- `v3-native.jsonl`、`v3-native-check.json`：官方正常 `main.lua` 入口，剧情模式、解剖选区、出生与实际游玩；实际 seed=314159、v3、216 细胞。观察到感染、潜伏、产毒、跨区域移动、分裂与切群，推进到第五阶段，日志 `debug_run=false`。辅助脚本只发送正常 OS 输入，没有修改游戏状态；后续要求不录屏，最终检查 frames=0。
- `small-window-v3.png`：960×600 外框的小屏布局；此前正常窗口外框 1360×900，客户区 1338×844。触摸真实设备、原生逐项目标点断言和整局胜利没有在本轮完成；坐标精度由自动回归覆盖。
