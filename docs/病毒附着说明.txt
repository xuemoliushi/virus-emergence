表面吸附病毒 —— 交付说明
================================================================

一、这一套是干什么的
  玩家能直接看到的"即时反馈"：一个很小的流感病毒**吸附在细胞边缘**，
  并且**细胞被接触的那一块膜亮起来**（亮的永远是细胞，不是病毒）。
  程序在运行时根据病毒与细胞的真实接触点摆放，**不能把病毒画死在细胞上**。

二、文件
  virus_attached.png              合成示例（particle + glint 叠在一起的样子），仅作参考
  virus_attached_particle.png     病毒本体         192×192 硬边像素画
  attachment_glint.png            接触亮点         192×192 柔边叠层
  virus_attached_scene_alpha.png  透明蒙版大图     1600×1600（背景全透明）
  virus_attached_scene_dark.png   暗底大图         1600×1600（同样构图，方便观看）
  virus_attached_meta.json        摆放参数（见下）
  预览/                           验收图（落位检查、尺寸对比、游戏内观感）

三、三件的关系
  三张图**同画布、同中心**（192×192，中心 (96,96)），可以按下面的顺序直接叠：
      细胞 → attachment_glint → virus_attached_particle
  · glint 的像素**全部在病毒剪影之外**，所以叠上去病毒本体一点光都不会沾
  · particle 是硬边（alpha 只有 0/255）；glint 是柔边（0/76/152/212/255）

四、摆放规则（程序照这个做）
  记 meta.json 里的：
      contact  = 接触点 P（画布坐标，中心是 (96,96)）
      outward  = 外向单位法线 d      r_rim = 47.5（接触刺突尖端到中心的距离）
  1) 病毒中心 = P + n × (r_rim − 8) × scale
     n 是细胞在该接触点的外向法线；(r_rim − 8) 让刺突**扎进膜里**一点，
     scale = 0 会变成"刚好相切"，看起来像病毒浮在细胞外面。
     scale 建议：细胞前景直径的 21% 对应病毒本体 96px。
  2) 把精灵里的 d 旋转到 −n：rot = atan2(d × (−n), d · (−n))。
     ⚠ 交给 PIL rotate() 时要取负号（PIL 是视觉逆时针，数组坐标 y 向下）。
  3) ⚠ **attachment_glint 必须按细胞轮廓裁剪**：
         glint_alpha_final = glint_alpha × 同位置的细胞 alpha
     不裁的话，细胞轮廓的转角/突起处光斑会有一小半挂到细胞外的背景上，
     半透明暖色压在近黑底上会变成**脏褐色斑块**。
     光斑必须画在**膜层之上**、病毒之下。

五、验收结论（都已通过）
  · 三图同画布 ✓；叠回还原可见区 RGB 最大差 1.00/255、alpha 最大差 0.00 ✓
  · glint 落在病毒剪影内的像素 = 0 ✓（病毒完全不上光）
  · 亮点峰值距接触点 P 仅 2.61px，方向朝膜内 ✓（3 个角度实测一致）
  · 透明蒙版审计 8/8 合规：四角 alpha=0、透明区无杂色、直通 alpha ✓
  · 5 个角度逐个放大目视确认：光斑都在膜上，没有挂到背景 ✓

六、这一包怎么来的 / 怎么再生成
  · 病毒本体派生：art/virus/virus_F2_B.png → 96px（LANCZOS + 量化 20 色），
    脚本 tools_derive_small_virion.py
  · 三件套生成：tools_make_virus_attached_v3.py --canvas 192
    （亮点形状参数 RU=23 / RV=26 / SOFT=1.6 / U0=1.5，想改大小就传 --ru/--rv）
  · 大图：tools_render_virus_scene.py --canvas 1600 --count 7
  · 打包（本目录）：tools_pack_virus_attached.py
  源文件常驻 art/细胞分层/（拆层流水线也用它），本目录是**交付快照**；
  改了源文件后重跑一次打包脚本即可同步。
