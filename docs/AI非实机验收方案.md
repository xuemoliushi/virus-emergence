# 三项 AI 修复的非实机验收

验收对象是追踪失忆缓冲、清理残骸解除伪装、失效留守释放自主性。测试直接执行当前 Core Lua 5.4，不启动原生窗口、浏览器、本地预览或远端构建，不提交代码。

## 场景矩阵

正式地图配置保持 v5、120×144 米、960 个细胞；固定种子为 314159、271828、161803。除选择种子、通过公开测试入口获得卡牌及明确注明的局部布置外，免疫参数、警戒规则、速度、感染周期、帧调度预算、实体表和业务函数均保留生产实现。

| 场景 | 验收条件 | 证据性质 |
| --- | --- | --- |
| Base：无卡追踪 | 检测范围外不能首次锁定；已锁定目标在缓冲圈仍被跟踪，预警未结束不受伤；超出失忆圈释放目标。 | 当前正式地图上的局部边界夹具，重新布置现有巨噬与群的位置。 |
| Base：警戒 VI 遮挡 | 在生成地图中找到真实墙体遮挡；失去视线后移除实时目标，搜索坐标只等于最后可见快照。 | 明确将警戒选择为 VI 的等级边界夹具，不宣称无卡自然开局具有 VI 能力。 |
| Camouflage：无卡／有卡对照 | 无卡停留不获得伪装；获得残骸伪装后按真实停留计时生效；巨噬完整预警、蓄力、清理后，在同一个固定步解除掩护；清理只一次，细胞仍为 DEAD。 | 用真实 KillCell 入口安排一处残骸；布置现有实体位置，清理与停留走完整 World.Update，不强制攻击状态或计时结果。 |
| Commands：无小脑 | 集群调度的安全无目标留守仍等待；遇险后释放指令，但群不获得自主选靶、感染、逃逸或自动分裂。 | 通过真实 Split 与 UseSkill 操作；初始卡使用 SimState 测试获得入口。 |
| Commands：有小脑 | 小脑自行选取实际细胞，留守记录其目标；目标经真实接触感染转换后，下一步释放整个指令并恢复自主性；遇险恢复 flee；集合继续尊重玩家指令，接管清除指令。 | 在出生平静区寻找不与其他细胞重叠的接触位置，布置现有免疫远离此局部感染过程；不手写 AI 目标或细胞感染进度。危险场景再把真实巨噬布置到近处。 |
| stress_base／stress_cards | 每种子各运行 60 模拟秒或直到自然结局；默认初始免疫与招募均保留，脚本输入驱动真实 SimState.Update；每秒检查质量、实体归属、唯一控制群、细胞六态、边界、预约与自动分裂门槛。 | 无实体位置或细胞状态注入的脚本化稳定性检查；指定卡组合为集群调度＋分群小脑＋残骸伪装。出现正式选卡时脚本选择第一项，并在报告记录次数。 |
| stress_active | 每种子运行至少 120 模拟秒或直到自然结局，脚本玩家用实际移动输入接近局部可达细胞；至少触发真实感染与真实病毒释放。默认免疫警戒、攻击和招募照常；不布置实体位置或感染状态。 | 实际传播与免疫响应的稳定性；记录感染、释放、清除与免疫数量。不是玩家策略、胜率或平衡验收。 |
| 确定性重放 | 314159 的实际传播场景在全新 Lua 环境重跑；每秒状态样本和最终所有细胞状态／病程、群与免疫的行动坐标和目标、游离病毒、质量统计、RNG 指纹相同。 | 验证该输入序列的重复性；不证明所有输入或所有种子都确定。 |

所有局部场景保留完整 960 个细胞及实际地图，不使用历史小地图，不把尚未运行的断言记为通过。场景失败时报告应保存断言、最新轨迹及日志，退出码非零；不能通过取消危险、加快感染、替换 AI 函数或降低断言标准来抹除失败。

## 运行与产物

```powershell
python -B tests/ai_non_runtime_acceptance.py
```

Python 需要 Lupa Lua 5.4；脚本可复用本项目 `.tmp/test-deps` 中的本地测试依赖。每个场景建立独立 Lua 环境，防止卡牌、测试配置或预约跨例污染。可用 `--only Base`、`--only Camouflage`、`--only Commands` 等重现单类场景；完整验收使用默认参数。

- `validation/ai-non-runtime/checks.json`：场景结果、逐项断言数据、模拟时间、压力样本、重复性、执行环境，以及本轮 Core 源码的 SHA-256。
- `validation/ai-non-runtime/report.md`：可读摘要与证据边界。
- 执行前后重新计算源码指纹；运行期间源码变化会使整体结果不通过。

整体通过要求：所有矩阵场景 PASS、确定性重放一致、源码指纹不变。运行耗时仅作记录，不作为原生 FPS 或手机性能结论。单类试跑没有重放，不等价于完整验收。

## 尚不能验收的内容

本方案可以验收这三项行为修复及其卡牌解锁边界，也能发现当前正式地图中的局部行为问题。它不能替代原生输入、界面提示、画面碰撞观感、音频、渲染性能、完整玩家路线、卡池获得难度和长局平衡验收，也不能据此宣布“涌现令人意外且好玩”。

后续四类规则接入后，此套 19 场景已重新执行并通过，使用更新后的默认模拟，重放指纹补充场强、待释放脉冲、防御、负载、识别及小脑探索记忆。新增规则的 18 场景与 103 项回归见 `四类涌现规则.md` 和 `validation/ai-emergence/`。
