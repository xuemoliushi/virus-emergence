# 手机端适配说明（2026-10-19）

目标：在不改玩法数值、不改六阶段规则、不动 `urhox-libs/` 的前提下，补上手机触控操作和小屏 UI 布局。桌面端的行为和文案保持原样。

## 触屏判定

见 `scripts/UI/MobileLayout.lua` 中的 `M.IsTouch(hud)`。满足以下任一条件即视为触屏：

1. `hud.touchSeen_` 为真，或 `M.touchSeen` 为真（本次运行出现过真实触摸，由 HUD 的 PointerDown 监听调用 `MarkTouch()`）；
2. `PlatformUtils.NeedsVirtualJoystick()` 为真（原生移动平台或开启了触摸模拟）。平台查询报错时（例如无 `input` 全局）按非触屏处理。

摇杆显示（`HUD:RefreshJoystickVisibility`）使用同一判定，保证布局和摇杆状态一致。
