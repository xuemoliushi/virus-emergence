潜伏期内部颗粒 latent_particles —— 交付说明
================================================================

一、这一套是干什么的
  病毒打进去了，但还没开始释放 —— **细胞内部安静地在动**。
  这一层就是那种"活动"的唯一视觉：14 颗极小的**荧光黄**颗粒，
  撒在已核准红细胞的**暗栗色内部**，疏密不均，少数几颗暗、一两颗稍亮。
  ★ 潜伏期的硬指标：**能看到活动，但明显弱于释放期**（见第四节实测）。

三、怎么叠（零换算）
  latent_particles.png 与 cell_body.png **同画布、同中心**，叠放时直接 (0,0) 对齐，
  不需要任何缩放或偏移换算。渲染顺序：
      cell_body → cell_membrane → cell_vacuole → latent_particles →（感染色斑）→ glint → 病毒
  ★ 颗粒**必须夹在液泡之后、发光/病毒之前**：压在内层之上才像"细胞内部的东西"，
    放到发光层之上会显得浮在表面。

四、两条硬指标（都已通过，数字是现场量的）
  1) 尺度 —— 颗粒必须"极小"，绝不能读成"一堆大病毒"
     颗粒外接 32px = 细胞前景 807px 的 1/25，
     只有病毒(121px) 的 1/3.8；
     实机（细胞前景 128px）上每颗约 5.1px。
     尺寸档位（改生成器 `--tex` 即可，画布/撒点掩膜/最小间距会自动重算）：
         tex 10 → 外接 20px
         tex 13 → 外接 26px
         tex 16 → 外接 32px　★ 现在这版（2026-10-06「色块搞大一点」→ 两个都做）
         tex 19 → 外接 38px
     再大就要留意：撒点掩膜按 32px 半径内缩，内部可用区会变小、颗粒数上限下降。
  2) 亮度 —— 潜伏必须**明显弱于**释放
     最亮档 luma 186 < 病毒 90 分位 189（硬判据，余量仅
     3.2），更低于病毒峰值 204
     与接触亮点 251。
     ★ 这一版是「荧光黄」（第 3 版），色相演进：
       琥珀橙（G/R 0.61）→ 黄（G/R 0.83）→ **荧光黄（B/R 0.00，G/R 1.05）**。
       现行色阶 luma 118 / 156 / 175 / 186
       （最热档与上一版黄基本持平，说明"荧光"确实不是靠加亮度换来的）。
       ★★「荧光」不是靠更亮做到的，而是两件事：
          ① **蓝通道归零** B/R = 0.00 —— 荧光黄是自发光色，现实里没有蓝成分；
             蓝通道一旦不为 0 就变"加白的淡黄"，荧光感立刻消失
          ② **绿不比红低** G/R = 1.05 —— 荧光笔那种黄其实是偏绿的（chartreuse / 电光黄）
       证据：luma 只从 185 挪到 186（+1），
       但 B/R 从 0.21 掉到 0、G/R 从 0.83 升到 1.05，视觉上完全换了一个色。
       想更亮就得抬亮度，那要动判据 —— 见下。
       **现在已经顶到天花板**：再往上加就会越过病毒 90 分位，
       那要先改「明显弱于释放期」这条判据（需要先确认再动）。
       预览/ latent_fluorescent_ladder.png 给了三档备选：
           ① 守判据（＝现在这版）luma 186　✓
           ② 与病毒本体齐平 luma ≈ 203　✗ 越过病毒 90 分位
           ③ 荧光笔级 luma ≈ 221　✗（≈接触亮点 90 分位）
         要 ②③ 的话说一声，同时得把判据从「< 病毒 90 分位」放宽。
     整片细胞的**暖色发光总量**实测：
         释放期（7 病毒 + 7 亮点）1558
         潜伏期（14 颗颗粒）    204
         →  潜伏 = 释放期的 **13.1%**（上限 45%）   ✓
  色阶（相对细胞内部底色 36，逐级抬亮，全部为像素硬边）：
     外圈 118 → 中层 156 → 核心 175
     → 最热 186（最热色**只给那一两颗稍亮的**，其余不许用）
  参考色值：外圈 [126, 136, 0] / 中层 [170, 180, 0] /
           核心 [192, 200, 0] / 最热 [203, 213, 0]
  3) 区分度 —— 别指望"比细胞自带的东西更亮"来认出潜伏活动，认不出来
     细胞**自带**的粉白小亮点实测 luma 上限 253，**比潜伏颗粒(185)还亮**，
     数量 76 个、外接 10px。
     所以识别潜伏期靠的是另外两个维度：
        色相：自带斑点 RGB≈[245, 189, 199]（粉白，B/R 0.81）
              潜伏颗粒 RGB 见上（荧光黄，B/R 0.00）
              —— 自带斑点的蓝通道是红通道的 0.81 倍，
                 潜伏颗粒是 0.00（归零），蓝通道彻底分开，同屏一眼能分开
        尺寸：32px vs 自带 10px，大一倍多
     预览/ latent_particles_sheet.png 最后两格就是同倍率同窗口的对照
     （左：自带粉白斑点；右：潜伏颗粒）。

五、动态（程序控制，低频脉冲，不要做成爆发）
  颗粒数量 / 位置 / 亮度档一律**程序控制**，不要写死在贴图里。
  meta.pulse:
    周期 2.6~5.2 秒，正弦调制 alpha；
    alpha 范围 0.55~1.00（压暗但不熄灭）；
    每颗的相位见 meta.particles[].pulse.phase —— **必须错开**，
    整片同时一起呼吸看起来是"爆发前兆"，不是潜伏。
  实现上二选一：① 直接用 latent_particles.png 整层做整体 alpha 调制；
                ② 按三档单体精灵逐个撒点、逐颗调 alpha（推荐，颗粒感更真）。
  ★ 一个容易搞错的地方：因为相位错开，**整片的发光总量本来就近乎恒定**
    （实测 134~176，只有 76%~100%），
    别指望整片一起变亮变暗 —— 「能看到活动」靠的是**个别点在各自呼吸**：
    单颗粒实测 alpha ×0.56 ~ ×0.95
    （本包最亮那颗，周期 3.15s）。
    预览/ latent_pulse_strip.png 上行是实机视距（整体安静），
    下行是同一颗按原始像素放大 8×（呼吸一目了然）。

六、撒点禁区（程序自己撒点时同样要守）
  · 只在 cell_body alpha>=250 的实心区内（图透明处 = 细胞外，绝不能落）
  · 离细胞边缘 > 67px（0.20×内切半径）（不许贴着膜）
  · 离液泡边缘 > 12px（不许掉进液泡）
  · 颗粒之间最小间距 83px
  随本包附带的 latent_particles.png 已经守住了这三条（越界像素实测 0/0/0），
  直接用它最省事；要程序自己撒点就照上面的数来。

七、验收结论（都已通过）
  · 四角 alpha = [0, 0, 0, 0] ✓；透明区颜色 = 最近可见色外扩（缩放不会拉黑边）✓
  · 只做/只用**荧光黄**一个色相（B/R=0.00 蓝通道归零、G/R=1.05 绿不低红），
    **没有**膜、没有液泡、没有背景 ✓
  · 三档单体均外接 32×32px、像素硬边（NEAREST 放大后台阶清晰，无柔化）✓
    ★ 荧光**没有**用发光/羽化去实现：全部是硬边像素 + 单一色相，
      在任意背景色上都可直接叠（不需要加色混合 / 不需要 bloom 就有荧光观感）✓
  · 越界检查：沾膜 0px ／
    沾液泡 0px ／
    出细胞 0px ✓
  · 稀疏度：内部（膜带以内）覆盖率 3.96%（粗上界 4.54%）
    —— 覆盖率会随颗粒变大自然上升，**不能**当"够不够疏"的判据；
    真判据是**间距**：最近两颗中心距 55px
    = 1.71 个颗粒外接（要求 ≥ 0.9，不许重合）✓
  · 颗粒在细胞上的落点 = meta.particles[].centre，已逐点比对与 PNG 像素一致 ✓
  · 脉冲自检：最暗相位单颗粒 alpha 仍 ×0.56 不熄灭，
    局部中位抬亮 +35~+45
    （细胞内部底色 36）→ 看得见在动，但不刺眼 ✓
  · 透明蒙版审计全绿 ✓

八、这一包怎么来的 / 怎么再生成
  · 生成：tools_make_latent_particles.py（**程序生成**，seed=20261006，非 AI 出图）
    改尺寸：--tex（10→20px / 13→26px / 16→32px★ / 19→38px）
    改色阶：直接改脚本顶部的 C_HALO / C_MID / C_CORE / C_HOT 四个常量
    —— 数量/位置/色阶可复现；AI 出图给不了可复现的点位，
       而且"单个小亮点"这种件 AI 只会给出模糊水滴。
  · 预览与实测：tools_preview_latent_particles.py
    → output/_work/latent_particles_check.json（本说明第四节的数字就来自这里）
  · 打包（本目录）：tools_pack_latent_particles.py
  源文件常驻 art/细胞分层/（拆层流水线也用它），本目录是**交付快照**；
  改了源文件后重跑打包脚本即可同步。
