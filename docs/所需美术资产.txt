下面按 **18天、6人、2D俯视微观风格、玩家操控病毒群体** 的范围列出一套可完成的美术资产清单。重点是：**少做静态图，多做可组合的图层和程序特效**，避免为每个病程状态生成完整大图。

# 一、资产总览

MVP建议控制在：

- 静态背景：6～8张
- 角色和细胞素材：15～20个
- 特效素材：10～15个
- UI图标和面板：15～20个
- 主要动画：15组左右

不建议制作：

- 每个病毒独立的复杂动画
- 每个细胞都使用完全不同的贴图
- 每种病程都重新生成一整张场景
- 真实无限缩放地图
- 大量器官和细胞类型

---

# 二、第一优先级资产

这些资产没有完成，游戏的核心体验就无法成立。

## 1. 风格参考图

数量：1张

用途：

- 统一细胞层画风
- 统一颜色、发光和留白
- 作为后续图片生成的参考图

要求：

- 16:9
- 正俯视
- 黑色或深紫色组织背景
- 4～6个细胞
- 少量病毒颗粒
- 一处感染区域
- 无UI、无文字、无培养皿边框

建议文件名：

```text
style_reference_cell_layer.png
```

## 2. 小鼠个体层资产

### 小鼠主体

建议制作5种状态：

1. 健康
2. 早期感染
3. 中度感染
4. 重度感染
5. 康复

死亡状态可以使用“静止躺下”的单独图片，也可以使用重度状态加程序动画表现。

建议每种状态制作：

- 1张侧面或三分之二侧面主体图
- 1张轻微动作变体，或者由程序做上下浮动和呼吸动画

总量：

```text
小鼠主体：5～6张
```

不建议为每个状态制作完整不同的小鼠，而是尽量保持：

- 体型一致
- 颜色一致
- 耳朵、尾巴和身体比例一致
- 通过姿态、眼睛、鼻部、呼吸和颜色表达病情

### 小鼠背景

数量：2张

```text
mouse_scene_healthy.png
mouse_scene_sick.png
```

可以只做一套实验环境背景，通过灯光、粒子和色调变化表现病程，不需要多张复杂房间图。

## 3. 组织层资产

组织层不做复杂器官剖面，主要做一片暗色组织内部的局部区域。

### 组织背景

建议制作3张：

1. 健康组织区域
2. 感染扩散区域
3. 严重损伤区域

```text
tissue_healthy.png
tissue_infected.png
tissue_damaged.png
```

背景中应包含：

- 深色组织底纹
- 少量分支纤维
- 流体通道
- 稀疏颗粒
- 局部感染热点

### 组织状态遮罩

建议额外制作以下透明图层：

```text
inflammation_overlay.png
damage_overlay.png
immune_signal_overlay.png
virus_flow_overlay.png
```

这些图层可以通过透明度、颜色和缩放动态变化，减少需要生成的完整背景数量。

### 组织区域标记

数量：3～5个

用于表示玩家可选择的病毒策略区域：

```text
region_normal.png
region_high_risk.png
region_infected.png
region_immune_pressure.png
```

这些不必做成明显的按钮，可以是局部边缘、流体纹理或区域亮度变化。

# 三、细胞层资产

细胞层是主要视觉卖点，需要保证数量少但辨识度高。

## 1. 健康细胞

建议制作4个形态变体：

```text
cell_healthy_01.png
cell_healthy_02.png
cell_healthy_03.png
cell_healthy_04.png
```

每个细胞应有：

- 不规则扁平轮廓
- 绿色或青绿色边缘
- 深色内部
- 一个主要液泡
- 少量颗粒
- 少量短突起

不要把细胞画成完全规则的圆形或六边形。

## 2. 感染细胞

建议制作3个阶段：

```text
cell_infected_early.png
cell_infected_active.png
cell_infected_damaged.png
```

对应：

- 初期感染：内部颗粒增加，边缘略偏暖
- 活跃感染：内部橙红发光，病毒活动明显
- 严重受损：边缘不稳定，内部结构破碎

感染细胞不建议全部重新生成。可以使用健康细胞作为基础，再叠加：

- 暖色遮罩
- 内部颗粒
- 脉冲效果
- 出芽效果
- 边缘变形

## 3. 死亡细胞和碎片

建议制作：

```text
cell_dead_01.png
cell_dead_02.png
cell_debris_small.png
cell_debris_large.png
```

死亡细胞要保持非血腥、非写实，表现为：

- 亮度降低
- 内部结构消散
- 边缘断裂
- 少量碎片残留

## 4. 巨噬细胞

建议制作2个形态变体：

```text
macrophage_01.png
macrophage_02.png
```

要求：

- 俯视
- 形状比普通细胞更大
- 有不规则流体边缘
- 有明显伪足
- 内部有颗粒和液泡
- 使用青绿色或蓝绿色
- 不要有脸和拟人化特征

## 5. T细胞

建议制作2个形态变体：

```text
t_cell_01.png
t_cell_02.png
```

要求：

- 体型小于巨噬细胞
- 比普通细胞更紧凑
- 蓝色或蓝紫色边缘
- 轮廓清楚
- 不需要武器、眼睛或表情

# 四、病毒资产

病毒不应生成成大型复杂球体。实际画面中应以“小型个体和群体粒子”为主。

## 1. 病毒主体

建议制作3种尺寸：

```text
virus_small.png
virus_medium.png
virus_large.png
```

它们可以是同一设计的不同尺寸版本。

要求：

- 暖橙、橙红、暗红色
- 远小于细胞
- 只有简单轮廓和少量突起
- 不要眼睛、嘴巴和拟人化表情
- 不要画成细菌或噬菌体

## 2. 病毒群体粒子

建议制作：

```text
virus_particle_soft.png
virus_particle_bright.png
virus_particle_trail.png
virus_cluster.png
```

用途：

- 远处病毒
- 病毒聚集
- 病毒移动
- 感染扩散
- 病毒数量变化

其中大多数可以通过程序粒子系统完成，不需要全部使用图片。

## 3. 病毒变异外观

18天版本最多做3种：

```text
virus_variant_attachment.png
virus_variant_replication.png
virus_variant_hidden.png
```

变化只需要体现在：

- 表面突起数量
- 发光强度
- 颜色深浅
- 内部颗粒
- 外轮廓轻微区别

不要把变异病毒设计成完全不同的怪物。

# 五、免疫和感染特效资产

## 1. 病毒感染特效

```text
effect_contact_flash.png
effect_entry_ring.png
effect_infection_pulse.png
effect_replication_particles.png
```

用途：

- 病毒接触细胞
- 病毒进入细胞
- 感染状态形成
- 细胞内部复制活动

## 2. 病毒出芽特效

建议制作3个阶段：

```text
effect_budding_01.png
effect_budding_02.png
effect_budding_03.png
```

表现：

1. 细胞边缘出现小亮点。
2. 亮点逐渐形成小病毒。
3. 病毒从细胞边缘分离。

这个过程最好由程序控制位置和缩放，图片只提供形状和光效。

## 3. 病毒群体行为特效

```text
effect_virus_aggregate.png
effect_virus_spread.png
effect_virus_hide.png
effect_virus_migration.png
```

用途：

- 聚集策略
- 扩增策略
- 隐匿策略
- 迁移或扩散行为

这些不需要画成明确的图标，主要是粒子、轨迹和局部光照变化。

## 4. 免疫反应特效

```text
effect_immune_signal.png
effect_macrophage_engulf.png
effect_t_cell_contact.png
effect_clearance_particles.png
```

表现：

- 炎症信号扩散
- 巨噬细胞吞噬病毒
- T细胞接触感染细胞
- 病毒被清除后的残留颗粒

## 5. 组织损伤特效

```text
effect_tissue_crack.png
effect_tissue_fade.png
effect_cell_fragment.png
effect_repair_glow.png
```

注意组织损伤不使用血液、伤口或爆炸表现，使用：

- 纤维断裂
- 局部变暗
- 流体通道紊乱
- 细胞碎片
- 暖色或紫色残留

# 六、需要制作的动画

## 1. 小鼠动画

### 健康状态

- 正常呼吸
- 正常走动或轻微移动
- 耳朵和尾巴轻微摆动

### 感染状态

- 活动频率下降
- 身体轻微蜷缩
- 呼吸加快
- 鼻部轻微分泌物动画
- 偶尔抖动或停顿

### 重症状态

- 明显呼吸起伏
- 身体保持低伏
- 活动停止或极少
- 轻微颤动

### 康复状态

- 呼吸恢复
- 活动逐渐增加
- 身体姿态恢复

小鼠动画不需要逐帧手绘很多帧。可以采用：

- 2～4帧循环
- 程序缩放和位移
- 呼吸骨骼或局部变形
- 粒子和透明度变化

---

## 2. 镜头动画

这是本项目必须重点完成的动画。

### 个体层到组织层

- 镜头向小鼠呼吸道区域移动
- 局部区域逐渐变暗
- 组织纹理和感染热点出现
- 短暂遮罩或模糊过渡

### 组织层到细胞层

- 镜头聚焦当前感染区域
- 细胞逐渐放大
- 病毒粒子和内部颗粒显现
- 进入正俯视微观场景

### 返回上层

- 细胞层逐渐缩小
- 回到组织区域
- 保留当前感染状态和病毒分布

不需要制作真实无限缩放。重点是让玩家感觉自己一直在观察同一个区域。

---

## 3. 病毒动画

### 基础运动

- 缓慢漂移
- 小范围随机移动
- 遇到组织结构时改变方向
- 靠近细胞时减速或停留

### 病毒聚集

- 周围病毒逐渐向一个区域靠拢
- 局部密度增加
- 聚集区域亮度略微提高

### 病毒扩散

- 病毒从感染点向外移动
- 逐渐出现新的感染热点
- 运动轨迹变长

### 病毒隐匿

- 亮度降低
- 移动速度降低
- 部分病毒暂时隐藏
- 感染区域的亮度减弱

### 病毒附着

- 病毒靠近细胞边缘
- 短暂停留
- 出现小范围接触亮点

### 病毒进入

- 病毒缩小或淡入细胞内部
- 细胞边缘出现短促脉冲

### 病毒复制

- 细胞内部颗粒增加
- 内部亮点产生脉冲
- 颗粒沿流体纹理移动

### 病毒出芽

- 感染细胞边缘生成新病毒
- 新病毒逐渐离开细胞
- 病毒数量增加

---

## 4. 细胞动画

### 健康细胞待机

- 内部颗粒缓慢流动
- 液泡轻微变化
- 边缘亮度缓慢起伏

### 感染细胞

- 细胞内部暖色脉冲
- 颗粒数量逐渐增加
- 细胞边缘轻微变形
- 局部颜色由绿色转为橙红

### 受损细胞

- 轮廓轻微抖动
- 内部结构逐渐消散
- 边缘出现断裂
- 少量碎片脱落

### 死亡细胞

- 亮度下降
- 颗粒停止运动
- 细胞逐渐变暗
- 变成碎片或残留结构

### 组织修复

- 附近健康区域亮度恢复
- 暗色裂缝逐渐缩小
- 组织颗粒重新出现
- 感染暖色逐渐退去

---

## 5. 免疫细胞动画

### 巨噬细胞

- 缓慢移动
- 伪足伸缩
- 接近病毒群
- 包围病毒
- 吞噬后内部出现亮点
- 吞噬完成后亮点消失

### T细胞

- 快速接近感染细胞
- 在感染细胞边缘短暂停留
- 产生接触脉冲
- 感染细胞亮度下降
- T细胞离开或寻找下一个目标

### 免疫细胞出现

- 从画面边缘缓慢进入
- 由暗到亮
- 进入感染区域后活动增强

---

## 6. 个体症状动画

### 发热

- 小鼠耳朵和鼻部颜色略微变暖
- 身体轻微颤动
- 画面UI中体温数值变化

### 流鼻涕

- 小鼠鼻部出现少量透明液体
- 液体缓慢消失和生成
- 不要使用夸张的大块黏液

### 呼吸困难

- 小鼠胸部起伏加快
- 身体姿态下降
- 配合轻微呼吸线或粒子

### 活动下降

- 减少小鼠位移
- 延长待机时间
- 降低动作频率

---

# 八、哪些资产应该由AI生成，哪些应该程序制作

## 适合用AI生成

- 小鼠主体和状态
- 组织背景
- 细胞主体
- 巨噬细胞
- T细胞
- 病毒基础形态
- 风格参考图
- 大型静态特效参考图

## 适合用程序制作

- 病毒随机移动
- 病毒聚集和扩散
- 粒子轨迹
- 病毒数量变化
- 细胞颜色过渡
- 细胞亮度变化
- 感染脉冲
- 免疫信号扩散
- 镜头缩放
- UI进度条
- 组织损伤透明度
- 小鼠呼吸和轻微抖动

不要让AI生成大量逐帧动画。AI生成的连续帧容易出现：

- 细胞形状跳变
- 病毒大小不一致
- 颜色闪烁
- 细胞位置漂移
- 动画无法循环

# 十、18天内的制作顺序

## 第1阶段：第1～3天

完成：

- 风格参考图
- 小鼠健康状态
- 一张组织背景
- 健康细胞
- 感染细胞
- 病毒主体
- 巨噬细胞
- T细胞

目标是让程序可以用占位图跑通整个细胞层。

## 第2阶段：第4～8天

完成：

- 三尺度场景
- 病毒移动
- 感染脉冲
- 细胞颜色变化
- 病毒出芽
- 免疫细胞移动和接触
- 小鼠基本状态动画

## 第3阶段：第9～12天

完成：

- 组织健康、感染和损伤状态
- 聚集、扩增、隐匿策略表现
- UI图标和策略反馈
- 镜头过渡
- 康复和死亡结局画面

## 第4阶段：第13～15天

完成：

- 细胞变体
- 病毒粒子优化
- 免疫清除效果
- 小鼠症状表现
- 重要视觉反馈

## 第5阶段：第16～18天

只处理：

- 资源替换
- 动画卡顿
- 画面层级
- 颜色统一
- 关键Bug
- 打包和演示

不要在第16天之后再增加新的细胞类型或新的游戏机制。
