# 吸附、出芽与免疫追踪调整

2026-10-10。已根据本轮反馈修改正式细胞玩法绘制和免疫追踪。

后续修正：吸附只在一次连续接触期间固定；同一病毒群离开后再次靠近时，按本次真实进入方向重新定位，旧记录仍在淡出也会更新。局部感染色斑同时重置到该膜锚点，不再读取沿膜平滑移动的旧方向。吸附病毒按单颗真实病毒半径显示，与普通病毒大小一致，不使用病毒群半径或细胞直径的固定比例。见 [吸附位置与尺寸修正.md](吸附位置与尺寸修正.md)。以下 139 项为前一轮记录，本次独立验证见新说明。

| 项目 | 本轮调整 |
|---|---|
| 吸附闪烁 | 每次有效接触进入时重新定位，此次连续接触期间固定局部膜锚点和亮度；亮斑等待裁剪纹理时，病毒本体仍然显示 |
| 离开后消失 | 健康／暴露细胞保留吸附位置；离开后有 0.15 秒防抖宽限，再用 2.4 秒缓慢淡出。使用世界时间，暂停不推进。进入潜伏后沿用 0.8 秒附着淡出；死亡或真实游离病毒被移除时取消显示 |
| 潜伏颗粒 | 原来的 14 颗粒在产毒期继续显示，位置、图片和脉动相位连续；耗竭和死亡仍停止显示 |
| 出芽跳变 | 保留六张源图作为关键姿态，加上原膜起始姿态，补间为 25 帧／0.8 秒。芽体先对齐实际中心与尺寸再混合，膜和颈部采用预乘透明度补间，首帧与原膜完全一致。真实释放触发、每批最多三颗、0.12 秒位置交接与状态取消规则继续执行 |
| T 细胞目标 | 感染细胞优先。初次发现、巡逻靠近和已锁定后的目标复查都遵循职责；高优先级目标出现时重新完整预警 |
| 巨噬细胞目标 | 游离病毒优先，其次病毒群，再感染节点及残骸；已锁定节点后可以切换到新发现的病毒 |
| 免疫寻路 | 已锁定目标的追踪可沿真实区域中心与通道节点绕行；连接边检查完整身体半径及连续移动，不跨枝间暗区。发现范围、接触伤害、攻击蓄力和冷却规则保留 |
| 组织流 | 移动标记增加为三条轨迹，短线更长更亮，箭头更密，增加暗色描边与 1.6 像素基础线宽；方向和速度仍来自真实流场，青蓝影响范围仍默认关闭 |

吸附独立保存在只读表现模块 [AttachmentVisual.lua](../scripts/Game/Views/AttachmentVisual.lua)，不写原接触记录或感染进度。原接触快照增加接触段序号、进入时间和进入方向，诊断方向仍可随真实来源更新；屏幕吸附锚点只在本次连续接触期间固定。

本轮按要求调整了免疫模拟中的目标选择、巡逻与追踪，因此行动顺序和随后 RNG 消耗可能不同于上一轮；不再将旧免疫模拟逐步指纹作为本轮一致性结论。感染进度、释放规则和其他纯表现逻辑没有改成第二套模拟。

寻路入口：[ImmuneNavigation.lua](../scripts/Core/ImmuneNavigation.lua)、[ImmuneSystem.lua](../scripts/Core/ImmuneSystem.lua)。仅对已锁定目标绕行，不增加全图透视检测。目标切换只发生在锁定、预警和追踪阶段，每 0.25 秒复查一次；攻击中和冷却中不转移蓄力。
