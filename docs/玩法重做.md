# 病毒涌现模拟游戏玩法设计与程序实现规格

## 1. 项目定位

本项目是一款 2D 俯视视角的病毒群体模拟游戏。

玩家控制一个或多个流感病毒群，在小鼠呼吸道组织中移动、感染健康细胞、建立感染节点、躲避免疫细胞，并通过感染扩散和免疫反应共同推动炎症发展。

玩家的最终目标不是单纯让病毒群变大，而是：

> 在不被免疫细胞彻底清除的情况下，建立足够多的感染节点，诱导持续的免疫反应，使小鼠产生不可逆的炎症和组织损伤并最终死亡。

游戏的核心体验：

```text
控制病毒群移动
→ 接触健康细胞
→ 使感染圈填满
→ 细胞进入潜伏期
→ 感染细胞延迟释放病毒
→ 新病毒被玩家吸收、独立扩散或感染其他细胞
→ 玩家建立多个感染节点
→ 免疫细胞被吸引并产生炎症
→ 玩家分裂、合并、潜伏、诱导免疫或逃跑
→ 小鼠炎症和组织损伤达到不可逆阈值
→ 玩家获胜
```

本项目是游戏化模拟，不是科研级动物病程预测工具。

# 2. 最终胜利与失败条件

## 2.1 玩家胜利

玩家需要让小鼠进入不可逆死亡阶段。

满足以下任一条件，可以判定玩家胜利：

```text
全局炎症达到不可逆阈值
```

或：

```text
全局组织损伤达到死亡阈值
```

或：

```text
小鼠呼吸功能持续低于最低阈值
```

重要规则：

```text
只要炎症或组织损伤已经达到不可逆阈值，
即使之后玩家病毒群被免疫细胞清除，
玩家仍然判定为胜利。
```

这样玩家不需要让病毒永远存活，而是需要在被清除之前完成足够的感染和炎症积累。

## 2.2 玩家失败

满足以下条件时判定失败：

```text
玩家控制的所有病毒群都被清除
且全局炎症尚未达到不可逆阈值
且全局组织损伤尚未达到死亡阈值
```

玩家失败后显示：

```text
病毒群被免疫系统清除
小鼠尚未进入不可逆重症
```

## 2.3 胜利核心矛盾

玩家不应该完全躲避免疫系统。

```text
免疫反应太弱：
炎症积累不足，难以让小鼠死亡。

免疫反应太强：
病毒群会被快速清除。

理想玩法：
让免疫细胞攻击感染节点，
但让玩家主病毒群及时逃脱。
```

玩家需要利用免疫细胞制造炎症，同时避免主病毒群被彻底清除。

# 3. 游戏阶段和左上角阶段任务

> 2026-10-18 更新：当前阶段达成条件以 [六阶段达成条件](六阶段达成条件.md) 为准；本节下方七阶段任务保留为早期设计记录。

游戏必须在屏幕左上角显示当前阶段、当前阶段任务和任务进度。

## 3.1 左上角UI结构

左上角显示：

```text
阶段：阶段名称
主要任务：当前阶段任务
进度：当前进度 / 目标进度
提示：一条简短的动态提示
```

示例：

```text
阶段 1：建立感染

主要任务：
感染 2 个健康细胞

进度：
1 / 2

提示：
保持病毒群靠近细胞以填充感染圈
```

阶段任务不应只显示数值，也要给出玩家应该做什么的明确指引。

## 3.2 阶段一：建立感染

目标：

```text
完成第一个感染节点
```

建议任务：

```text
感染至少2个健康细胞
完成至少1个细胞的潜伏感染
收集第一批感染细胞释放的病毒
```

完成条件：

```text
至少存在1个LATENT或PRODUCTIVE状态的感染细胞
```

设计目的：

- 教玩家使用感染圈。
- 教玩家理解感染不会立即释放病毒。
- 教玩家等待感染节点发展。

## 3.3 阶段二：建立感染网络

目标：

```text
让多个感染节点同时运行
```

建议任务：

```text
同时维持2个感染节点
或让一个感染细胞在玩家离开后完成潜伏
```

完成条件：

```text
同时存在至少2个非HEALTHY、非DEAD的感染节点
```

设计目的：

- 教玩家离开感染细胞。
- 让玩家理解感染节点会在后台继续运行。
- 鼓励玩家不要只守着一个细胞。

## 3.4 阶段三：感染扩散

目标：

```text
让新释放的病毒独立感染一个新的健康细胞
```

建议任务：

```text
使感染细胞释放的病毒感染另一个玩家没有直接接触的细胞
```

完成条件：

```text
存在一个由ReleasedVirus直接完成感染的细胞
```

设计目的：

- 第一次明确表现“涌现”。
- 玩家看到自己的旧感染节点在离开后继续影响地图。
- 让新释放病毒不再只是自动回到玩家身边。

## 3.5 阶段四：进入更深区域

目标：

```text
从当前呼吸道层级进入更深的区域
```

建议任务：

```text
让玩家主病毒群到达气管或支气管区域
```

完成条件：

```text
playerMainSwarm.currentMacroRegion >= TARGET_REGION
```

设计目的：

- 引导玩家向地图深处移动。
- 让不同起始区域形成不同路线。
- 使地图具有空间推进感。

## 3.6 阶段五：制造免疫冲突

目标：

```text
让免疫细胞攻击感染节点，但主病毒群逃脱
```

建议任务：

```text
触发一次感染节点免疫攻击
并使主病毒群在攻击完成前离开警戒范围
```

完成条件：

```text
immuneAttackTriggered == true
and playerMainSwarmEscaped == true
```

设计目的：

- 教玩家利用免疫系统。
- 教玩家观察免疫预警。
- 教玩家区分感染节点和主病毒群。

## 3.7 阶段六：诱导炎症

目标：

```text
使多个区域产生持续炎症
```

建议任务：

```text
同时维持至少2个炎症热点
或使一个区域进入高炎症状态
```

完成条件：

```text
activeInflammationHotspots >= 2
or globalInflammation >= INFLAMMATION_MILESTONE
```

设计目的：

- 从单纯感染转向感染网络管理。
- 让玩家主动考虑感染节点位置。
- 准备最终胜利阶段。

## 3.8 阶段七：不可逆感染

目标：

```text
让小鼠进入不可逆炎症和组织损伤阶段
```

完成条件：

```text
globalInflammation >= irreversibleInflammationThreshold
or globalTissueDamage >= irreversibleDamageThreshold
```

进入该阶段后：

```text
玩家病毒群可以被清除，但不会取消胜利。
```

# 4. 呼吸道地图与开局区域选择

游戏使用玩家上传的肺部解剖图作为空间布局参考。

## 4.1 使用解剖图的方式

Agent需要：

1. 读取上传的肺部解剖图。
2. 识别主要空间关系：
   - 上呼吸道入口。
   - 气管主干。
   - 左右支气管分支。
   - 肺部深区。
3. 不直接把解剖图当作最终游戏地图。
4. 将解剖结构抽象成可玩的2D俯视组织地图。
5. 保留“由上向下、由主干向分支扩散”的空间关系。
6. 使用深色组织、流体通道、细胞簇和感染热点重新绘制游戏地图。

解剖图只作为：

```text
空间结构参考
```

不作为：

```text
最终背景图片
```

## 4.2 宏观区域

地图至少包含以下宏观区域：

```text
UPPER_AIRWAY
上呼吸道

TRACHEA
气管主干

BRONCHUS_LEFT
左支气管

BRONCHUS_RIGHT
右支气管

DEEP_LUNG
肺部深区
```

游戏不要求严格医学解剖精度，但必须让玩家理解：

```text
上呼吸道
→ 气管
→ 支气管
→ 肺部深区
```

## 4.3 玩家开局选择

游戏开始时，玩家选择一个初始区域。

可选区域：

```text
上呼吸道
气管主干
肺部深区
```

每个区域使用同一张地图，但拥有不同的初始病毒分布、感染节点和免疫压力。

### 上呼吸道开局

特点：

```text
一个中等规模的主病毒群
附近健康细胞较多
初始免疫压力较低
感染目标较密集
通向深部需要逐步推进
```

玩法：

```text
适合稳定建立感染网络
适合新玩家
感染过程较容易观察
```

### 气管主干开局

特点：

```text
一个中等病毒群
存在明显的流体通道
左右支气管都可以作为扩散方向
病毒容易被带向其他区域
```

玩法：

```text
适合分裂、跨区感染和路线选择
```

### 肺部深区开局

特点：

```text
病毒群规模较大或带有初始感染进度
附近存在高价值细胞
初始免疫压力较高
感染收益高但生存时间短
```

玩法：

```text
适合熟练玩家挑战
需要快速建立感染或使用机制卡逃脱
```

## 4.4 开局区域选择UI

开局选择界面显示一张简化的呼吸道地图。

玩家可以点击：

```text
上呼吸道
气管主干
肺部深区
```

点击区域后显示：

```text
区域名称
初始病毒群规模
初始感染压力
初始免疫压力
区域特点
```

示例：

```text
上呼吸道

稳定建立感染。
健康细胞较多，免疫压力较低，
但进入肺部需要经过气管和支气管。
```

不要把所有数值完整公开，只显示：

```text
低 / 中 / 高
```

并通过画面预览玩家即将遇到的环境。

# 5. 健康细胞和感染细胞状态机

## 5.1 细胞状态

```text
HEALTHY
健康

EXPOSED
接触感染中

LATENT
潜伏感染

PRODUCTIVE
活跃释放

EXHAUSTED
释放能力耗竭

DEAD
死亡
```

## 5.2 HEALTHY

健康细胞正常存在，可以被玩家病毒群或释放病毒感染。

## 5.3 EXPOSED

玩家病毒群靠近健康细胞后，细胞周围出现感染圈。

感染圈规则：

```text
病毒群距离细胞越近，感染圈增长越快。
病毒群密度越高，感染圈增长越快。
病毒群离开后，感染圈缓慢下降。
```

感染圈离开后：

```text
不会立即清零；
会保留当前部分进度；
如果长时间没有病毒影响，最终可以逐渐回落。
```

建议：

```text
感染圈下降速度 < 感染圈增长速度
```

这样玩家可以：

```text
暂时离开一个未完成感染的细胞，
之后再回来继续完成。
```

## 5.4 LATENT

感染圈填满后，细胞进入潜伏感染。

特点：

```text
不立即释放病毒
不需要玩家持续停留
潜伏计时在后台继续
细胞颜色逐渐改变
内部出现低频暖色脉冲
```

玩家可以离开并继续感染其他细胞。

## 5.5 PRODUCTIVE

潜伏计时结束后，细胞进入活跃释放状态。

释放采用分批机制：

```text
释放批次1：少量病毒
释放批次2：中等病毒
释放批次3：较多病毒
```

每次释放：

```text
在细胞边缘生成病毒
病毒进入周围组织空间
病毒不自动全部飞回玩家群
```

新释放的病毒可能：

```text
被玩家吸收
独立感染健康细胞
被免疫细胞清除
沿组织流移动
离开当前区域
```

## 5.6 EXHAUSTED

完成若干次释放后，细胞进入耗竭状态：

```text
释放数量下降
细胞亮度下降
内部活动减少
新感染概率下降
局部免疫信号增加
```

耗竭状态持续一段时间后进入DEAD。

## 5.7 DEAD

死亡细胞：

```text
不再释放病毒
不再产生感染圈
变为暗色残骸
产生少量细胞碎片
增加局部炎症
可能影响局部移动
```

# 6. 玩家病毒群

## 6.1 玩家主病毒群

玩家开始时拥有一个主病毒群：

```text
playerMainSwarm
```

主病毒群可以：

```text
移动
感染健康细胞
吸收释放病毒
分裂
合并
躲避免疫细胞
使用机制卡
```

## 6.2 病毒群规模

病毒群规模不是单纯正向成长。

规模增大：

```text
感染圈增长更快
吸收范围更大
更容易维持感染
```

规模增大代价：

```text
移动速度下降
转向速度下降
免疫可见度提高
更容易被免疫细胞锁定
```

## 6.3 病毒群分裂

分裂是基础能力，不需要卡牌解锁。

分裂操作：

```text
按下分裂键
→ 当前病毒群消耗一部分病毒质量
→ 生成主群和分群
→ 分群向鼠标方向弹出
```

分裂最多同时存在两个病毒群：

```text
主群
分群
```

分群可以：

```text
独立移动
独立接触健康细胞
独立完成感染圈
独立进入潜伏节点
独立等待释放
被玩家切换控制
```

分群不能拥有复杂自主AI。未被控制时：

```text
维持当前位置附近的缓慢移动
继续完成已经开始的感染
不主动进行复杂寻路
```

## 6.4 Tab切换控制

使用Tab切换当前玩家控制的病毒群：

```text
Tab：
主群 ↔ 分群
```

当前被控制的病毒群：

```text
显示明显轮廓
显示控制标记
接收玩家移动输入
```

非当前控制的病毒群：

```text
降低控制标记亮度
保持缓慢漂移
继续完成感染节点
```

## 6.5 病毒群合并

当主群和分群距离足够近时：

```text
显示合并提示
两个病毒群互相吸引
接触后合并
病毒质量相加
```

如果两个群体距离太远：

```text
不能立即合并
玩家必须切换控制并移动其中一个群体
```

如果分群被免疫细胞清除：

```text
主群继续存在
不会自动死亡
```

# 7. 新释放病毒的独立行为

感染细胞释放的病毒不应直接自动加入玩家病毒群。

## 7.1 ReleasedVirus状态

```text
RELEASED
新释放

DRIFTING
漂移

ATTRACTED
被玩家群吸引

INFECTING
正在感染其他细胞

CLEARED
被清除

LOST
离开区域或失活
```

## 7.2 玩家吸收

当释放病毒进入玩家病毒群的吸收范围：

```text
ReleasedVirus进入吸收范围
→ 被吸收
→ playerSwarm.mass增加
→ 播放短暂暖色吸收反馈
```

## 7.3 独立感染

当释放病毒接近健康细胞：

```text
进入细胞感染影响范围
→ 独立填充感染圈
→ 感染圈填满后形成新的LATENT节点
```

这次感染不要求玩家直接接触。

## 7.4 被免疫清除

释放病毒进入免疫作用范围时：

```text
有概率被清除
数量减少
播放微弱冷色清除效果
```

# 8. 机制卡牌系统

## 8.1 卡牌设计原则

卡牌不能只提供以下效果：

```text
感染速度+10%
病毒数量+20%
移动速度+15%
```

卡牌必须改变玩家的操作方式、风险关系或空间行为。

一张合格的机制卡应该让玩家产生新的行为：

```text
以前不能躲进细胞，现在可以。
以前只能自己吸引免疫，现在可以诱导感染节点。
以前只能控制一个群，现在可以利用分群欺骗免疫。
```

## 8.2 卡牌获取方式

第一版采用：

```text
达成特殊事件
→ 游戏暂停或减速
→ 随机显示3张机制卡
→ 玩家选择1张
→ 卡牌加入当前可用能力
```

卡牌事件不是固定时间触发，而由玩家行为和模拟事件触发。

每局建议最多获得3～5次卡牌选择机会，避免系统过于复杂。

## 8.3 卡牌触发事件

至少实现以下事件：

### 事件1：首次完成感染

```text
玩家第一次让感染圈填满
```

触发目的：

```text
让玩家获得第一个机制卡
```

### 事件2：首次完成潜伏

```text
玩家第一次让一个细胞进入LATENT
```

### 事件3：首次完成释放

```text
感染细胞第一次完成释放批次
```

### 事件4：首次吸收释放病毒

```text
玩家第一次主动回收感染节点释放的病毒
```

### 事件5：首次独立感染

```text
释放病毒在玩家没有直接接触的情况下感染另一个细胞
```

### 事件6：首次同时维持两个感染节点

```text
同时存在两个LATENT、PRODUCTIVE或EXHAUSTED以前的感染节点
```

### 事件7：首次完成分裂

```text
玩家第一次成功分裂
```

### 事件8：首次使用Tab切换控制对象

```text
玩家第一次在两个病毒群之间切换控制
```

### 事件9：首次成功合并

```text
分裂后的两个病毒群重新合并
```

### 事件10：首次逃脱免疫锁定

```text
免疫细胞已经锁定玩家群，
但玩家在攻击前成功离开警戒范围
```

### 事件11：首次诱导免疫攻击感染节点

```text
免疫细胞攻击感染节点，
而不是直接攻击玩家主群
```

### 事件12：首次跨宏观区域移动

```text
玩家从上呼吸道进入气管，
或从气管进入支气管/肺部深区
```

### 事件13：首次由分群独立感染细胞

```text
非当前控制的分群独立完成一个感染圈
```

### 事件14：首次损失分群但主群存活

```text
分群被清除，
主群仍然存在
```

### 事件15：首次形成双区域炎症

```text
至少两个宏观区域同时存在炎症热点
```

同一个事件每局只触发一次卡牌选择。

## 8.4 推荐第一版机制卡

第一版优先实现以下三张：

```text
细胞潜伏
诱饵分裂
免疫诱导
```

### 卡牌：细胞潜伏

玩家可以将当前病毒群藏入已经进入LATENT或PRODUCTIVE状态的感染细胞。

效果：

```text
当前病毒群暂时从场景中消失
免疫细胞无法直接锁定该病毒群
感染节点继续运行
经过一段时间后，病毒群从该节点重新出现
```

限制：

```text
只能进入已经完成一定感染进度的细胞
进入期间不能移动
如果该感染细胞被清除，玩家病毒群可能损失
重新出现时会产生短暂病毒信号
```

玩家玩法变化：

```text
空间逃跑
→ 躲入感染节点
→ 等待免疫细胞经过
→ 从另一个时间窗口重新出现
```

### 卡牌：诱饵分裂

玩家分裂时，可以将分群设置为诱饵群。

诱饵群：

```text
更容易被免疫细胞发现
释放更明显的病毒活动信号
可以向指定方向移动
主群短时间内降低被锁定概率
```

代价：

```text
诱饵群规模较小
可能被免疫细胞清除
分裂本身消耗病毒质量
```

玩家玩法变化：

```text
牺牲一个分群
→ 吸引免疫细胞
→ 主群绕路感染或逃跑
```

### 卡牌：免疫诱导

玩家选择一个活跃感染节点，主动提高其免疫信号。

效果：

```text
感染节点释放强烈感染信号
免疫细胞向该节点聚集
局部炎症快速增加
玩家可以提前逃离
```

代价：

```text
该节点会更快耗竭
释放收益减少
免疫细胞完成攻击后可能继续追踪玩家
```

玩家玩法变化：

```text
把免疫细胞引向一个已经不重要的感染节点
→ 制造炎症
→ 主病毒群离开
```

## 8.5 后续可选机制卡

这些不是第一版必做，但系统应预留扩展接口。

### 节点爆发

远程激活一个已经完成潜伏的感染节点，使其立即进入释放阶段。

### 碎片伪装

玩家进入死亡细胞碎片或损伤区后，暂时不被免疫系统锁定，但移动和感染能力降低。

### 分裂回声

使用一次分裂时，额外产生一个短暂、不可合并的微小分群。

### 反向聚集

让释放病毒暂时向玩家指定位置聚集，而不是自然漂移。

### 感染接力

当一个释放病毒独立感染新细胞时，允许玩家短时间内切换控制到该新感染区域附近。

### 节点转移

将玩家当前病毒群从一个已感染节点转移到另一个已完成潜伏的节点。

# 9. 组织流系统

组织流是第一优先级地图玩法，不需要真实流体模拟。

## 9.1 组织流的作用

组织流必须影响：

```text
玩家病毒群的移动
释放病毒的移动
感染节点之间的扩散
分群的控制难度
玩家选择路线
```

组织流不能只是背景动画。

## 9.2 流体通道

地图中生成若干条低亮度、弯曲的流体通道。

每条通道拥有：

```text
controlPoints[]
width
direction
strength
speed
branchId
```

通道表现为：

```text
深色组织中的低亮度颗粒流
少量连续的半透明流线
沿路径移动的微粒
```

## 9.3 流场计算

每个位置都有一个局部流向：

```text
localFlowDirection
localFlowStrength
```

病毒运动：

```text
velocity =
selfVelocity
+ localFlowDirection * localFlowStrength * flowInfluence
+ randomDrift
```

建议：

```text
释放病毒：flowInfluence较高
分群：flowInfluence中等
玩家主群：flowInfluence较低
```

这样玩家主群仍然可以控制，但环境会影响移动。

## 9.4 流区类型

至少实现三类区域：

### 低流速区

```text
速度慢
病毒容易停留
适合感染和回收
也容易被免疫细胞追上
```

### 高流速通道

```text
速度快
容易跨区传播
释放病毒容易被带走
玩家需要不断修正方向
```

### 紊流区

```text
方向不稳定
存在小范围旋转流
释放病毒容易分散
分群不容易重新合并
```

## 9.5 流体视觉实现

没有专用组织流美术素材时，使用程序生成：

```text
预设贝塞尔曲线
+ 半透明流线
+ 小型粒子
+ 低亮度噪声
+ 透明度随距离变化
```

不要生成明显的蓝色水流，也不要画成河流或管道。

建议颜色：

```text
背景：深紫黑
正常流：暗紫、暗红、低亮度青紫
感染附近流：带少量暖橙颗粒
免疫区域流：带少量冷青颗粒
```

## 9.6 流体与地图玩法

流体必须形成路线差异：

```text
高流速捷径：
移动快，但容易被带离目标。

低流速安全区：
容易控制，但容易被免疫追上。

紊流区：
适合躲避追踪，但分裂群体容易失散。
```

# 10. 随机地图生成

健康细胞不能使用规则网格，也不能完全随机散点。

地图采用：

```text
固定宏观解剖结构
+ 程序生成局部组织结构
+ Poisson Disk细胞采样
+ 密度场
+ 细胞簇
+ 流体通道
+ 可达性检查
+ 随机种子
```

## 10.1 地图宏观结构

宏观结构固定为：

```text
上呼吸道入口
    ↓
气管主干
   ↙ ↘
左支气管 右支气管
   ↘   ↙
肺部深区
```

具体形状参考上传的肺部解剖图，但不要求复制真实解剖轮廓。

## 10.2 程序生成的局部结构

每局随机生成：

```text
细胞簇位置
细胞密度
细胞大小
细胞旋转
高产细胞位置
警戒细胞位置
流体通道偏移
流速强弱
免疫入口位置
```

每局不随机改变：

```text
宏观区域连接关系
起始区域可达性
至少一条安全路线
至少一条高风险捷径
肺部深区存在
```

## 10.3 细胞簇

先生成3～6个细胞簇中心。

每个细胞簇拥有：

```text
center
radius
density
cellCount
cellTypeWeights
```

簇内使用Poisson Disk Sampling生成细胞位置。

细胞簇必须：

```text
内部较密
边缘逐渐稀疏
簇与簇之间有暗色间隔
不形成规则方格
```

## 10.4 Poisson Disk Sampling

细胞位置需要满足最小间距：

```text
避免细胞重叠
避免规则网格
形成自然间隔
```

局部最小距离由密度场决定：

```text
高密度区：最小距离较小
普通区：中等最小距离
流体通道：最小距离较大
低密度区：最小距离较大
```

## 10.5 密度场

每个位置计算：

```text
densityValue =
baseDensity
+ clusterInfluence
+ fiberInfluence
- channelInfluence
+ noiseValue
```

密度高的区域生成更多健康细胞，密度低的区域生成更少细胞。

## 10.6 流体通道附近的细胞

```text
通道中心：
低细胞密度

通道两侧：
中等细胞密度

细胞簇内部：
高细胞密度
```

通道不能完全没有健康细胞，否则玩家无法在传播路径上建立感染。

## 10.7 细胞数量建议

整个可玩地图：

```text
普通细胞：40～80个
高产细胞：3～6个
警戒细胞：2～4个
```

当前屏幕：

```text
高细节重点细胞：8～15个
低细节细胞：10～25个
总可见细胞：18～40个
```

玩家移动到下一个可感染目标的时间建议为：

```text
2～5秒
```

不应出现超过8秒没有目标的空白区域。

## 10.8 细胞类型

第一版至少有：

```text
普通健康细胞
高产细胞
警戒细胞
```

### 普通健康细胞

```text
感染难度普通
释放量普通
免疫信号普通
```

### 高产细胞

```text
感染时间较长
释放量较高
释放时产生更明显的免疫信号
适合玩家冒险争夺
```

### 警戒细胞

```text
容易触发局部免疫信号
释放量普通或偏低
会吸引免疫细胞
适合作为高风险目标
```

## 10.9 出生点规则

玩家出生点必须满足：

```text
附近存在2～4个普通细胞
至少存在一条可通行路线
不直接生成在细胞簇中心
不直接贴近免疫出生点
距离地图边缘适中
```

## 10.10 免疫出生点规则

免疫出生点可以位于：

```text
地图边缘
流体通道末端
感染热点附近的外围
玩家可能经过的支路
```

免疫细胞不能在游戏开始时直接出现在玩家旁边。

## 10.11 地图可达性检查

生成地图后必须进行检查：

```text
玩家出生点能否到达至少80%的普通细胞
能否到达至少一个高产细胞
能否到达至少一个深部区域
能否使用流体通道跨区移动
是否至少存在一条安全路线
是否至少存在一条高风险捷径
```

不满足条件时：

```text
丢弃当前地图
使用新的随机种子重新生成
```

# 12. 免疫细胞

免疫细胞不能出现后立即清空病毒群。

## 12.1 免疫攻击流程

```text
发现
→ 锁定
→ 预警
→ 追击
→ 接触
→ 清除或削弱
```

玩家应能观察到：

```text
冷色警戒圈
追踪方向
免疫细胞位置
攻击倒计时或预警
```

## 12.2 巨噬细胞

行为：

```text
移动较慢
靠近病毒群
清除外围少量病毒
处理死亡细胞和病毒碎片
```

巨噬细胞不能一次清除整个区域。

## 12.3 T细胞

行为：

```text
寻找高活跃感染节点或病毒群
锁定目标
显示冷色预警
接近目标
接触后削弱目标
```

T细胞可以攻击玩家病毒群，但必须有明显预警。

## 12.4 免疫与胜利目标

免疫细胞的攻击同时具有两面性：

```text
攻击玩家主群：
导致失败风险增加。

攻击感染节点：
增加局部炎症，有利于玩家达成胜利。
```

# 13. 模拟更新顺序

建议使用固定时间步长。

```text
每0.1秒：
更新移动、流体和碰撞表现。

每0.5秒：
进行一次病程模拟结算。
```

每次病程结算：

```text
1. 读取玩家当前控制群体状态。
2. 更新所有病毒群位置。
3. 应用局部组织流。
4. 更新感染圈。
5. 判断感染圈是否填满。
6. 更新潜伏感染计时。
7. 更新活跃释放批次。
8. 生成ReleasedVirus。
9. 更新ReleasedVirus的漂移。
10. 判断ReleasedVirus是否感染健康细胞。
11. 更新免疫细胞的发现、锁定和攻击。
12. 更新炎症。
13. 更新组织损伤。
14. 更新小鼠状态。
15. 检查阶段任务。
16. 检查卡牌事件。
17. 检查胜利或失败。
18. 向表现层发送事件。
```

# 15. 表现层关键反馈

## 15.1 感染圈

感染圈必须清晰表现：

```text
当前感染进度
感染圈增长
感染圈下降
感染完成
```

感染圈状态：

```text
低进度：暗红
中进度：橙红
高进度：亮橙
即将完成：出现短暂脉冲
完成：转为潜伏感染标记
```

## 15.2 潜伏感染

表现：

```text
细胞颜色变暗
内部暖色脉冲
低亮度感染标记
不立即释放病毒
```

## 15.3 活跃释放

表现：

```text
细胞膜边缘出芽
新病毒从细胞表面出现
病毒先散开
之后根据流体和距离移动
```

## 15.4 耗竭

表现：

```text
细胞亮度降低
释放频率降低
内部颗粒减少
边缘转向暗紫
```

## 15.5 组织流

表现：

```text
低亮度弯曲流线
稀疏微粒沿路径移动
流线不应像河流
不使用过强蓝色
```

## 15.6 分裂

表现：

```text
病毒群短暂压缩
向相反方向弹出两个群体
两个群体颜色和材质保持一致
当前控制群体有明显轮廓
```

## 15.7 合并

表现：

```text
两个群体边缘互相吸引
粒子逐渐集中
接触后出现短暂暖色脉冲
病毒质量合并
```

# 18. 最终玩法定义

本游戏的最终玩法是：

```text
玩家选择一个呼吸道起始区域
→ 控制病毒群移动
→ 通过感染圈感染健康细胞
→ 感染细胞进入潜伏并在后台继续发展
→ 玩家离开并建立多个感染节点
→ 感染节点分批释放新病毒
→ 新病毒可能被吸收、独立感染、被清除或被组织流带走
→ 玩家通过分裂、合并、Tab切换和机制卡管理多个病毒群
→ 免疫细胞攻击玩家群或感染节点
→ 玩家躲避直接清除，同时利用免疫攻击制造炎症
→ 阶段任务逐步推进
→ 炎症或组织损伤达到不可逆阈值
→ 小鼠死亡，玩家胜利
```

游戏的“涌现”主要来自：

```text
玩家的一次感染行为
→ 留下一个会自行运行的感染节点
→ 节点产生新的释放病毒
→ 新病毒独立感染其他细胞
→ 新感染节点继续运行
→ 免疫细胞改变病毒群路径
→ 玩家利用分裂、合并和卡牌重新组织策略
→ 最终形成玩家没有逐个直接操作的感染网络
```

核心设计原则：

> 玩家负责播种、移动、分裂、躲避和选择机制；系统负责让感染节点、释放病毒、组织流和免疫细胞共同产生后续结果。
