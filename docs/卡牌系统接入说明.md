## 入口与文件

细胞玩法左下操作区向下滚动，点击“卡牌测试 · 线框与文字”。三张卡通过独立测试按钮获取，真实生效并升级警戒。面板内另有0～Ⅵ警戒覆盖按钮，标注“调试覆盖”，不增加卡牌获得记录。继续按钮固定在面板底部，升级说明固定在面板上方。

## 分裂与三张卡

开局容量2，分裂门槛12。一次消耗`max(1,floor(质量×10%))`，剩余质量依原50%分配，保持8秒冷却、质量缩放弹射、最近有效移动方向及2秒合并保护。所有分裂入口检查容量；自动分裂停用。

隐藏或暂不可控制的存活群占名额，普通ReleasedVirus不占。合并或死亡释放名额。Tab按创建顺序跳过不可控制群；当前群死亡后自动接管其他可控制存活群，所有活群清除才灭团。

| 卡牌 | 稀有度 | 效果／前置 |
|---|---|---|
| 分裂扩容 | 稀有 | 容量2→4；不赠送质量或直接创建群 |
| 多群扩容 | 史诗 | 容量4→6；必须先获得分裂扩容 |
| 分群小脑 | 稀有 | 解锁未控制群的局部感染和避敌；没有扩容前置 |

卡牌本局不可重复获得。请求ID包含局标识，跨局旧请求与重复点击不能重复结算能力或警戒。

正式接口为`GrantCardChoice(reason)`、`GetEligibleCards(round)`、`CommitCardChoice(choiceId,cardId)`。正式候选必须是3张不同合法卡；当前合法池不足时明确失败，不推进轮次和历史。未选牌第n+1、n+2轮排除，第n+3轮回池；已获得牌永久排除。稀有度权重集中在Config，支持覆盖及合法补位，现值为临时开发参数。

本次没有启用正式六轮触发流程，没有补入未定稿能力。六轮与B3回归通过仅测试注入定义验证，测试牌不在游戏卡池中。

## 小脑与免疫

未解锁小脑仍保留漂移、组织流、弹射、接触感染、近距合并。解锁后启用等待、寻找健康细胞、感染与避敌；无安全目标时等待，不主动收集游离病毒、分裂或寻找合并。

小脑感知半径6米、决策间隔0.25秒、目标保留1.2秒。目标切换收益、危险解除滞回和预约超时集中配置。选细胞外围接触点，并裁剪可能穿入其他细胞的自主运动；实际运动仍交给原地图、碰撞和组织流。接管立即释放预约并清除AI驱动，感染进度保留。有限撤退不保证无损逃脱。

T细胞只选实际发现的活感染节点，优先产毒节点；巨噬细胞依次处理游离病毒、残骸、已发现玩家群。每个节点默认一个主要攻击者，每个粗网格游离病毒区默认一个主要处理者；外围合法站位和移动者小幅分离减少重叠。预约到期、目标死亡、接管与实体清理释放占用。

保持2.8秒预警、真实接触、蓄力与攻击冷却。每次合法命中一次结算，节点终态破坏只一次结算；死亡节点停止释放。感知丢失后不更新追踪坐标，搜索使用最后观察快照。

## 警戒行为

真实获取每次升一级，上限6。能力立即生效，显示升级说明并暂停。继续后新警戒行为等待5秒模拟时间；观察、选卡、失焦等暂停期间不计时。

| 等级 | 累积新增行为 |
|---|---|
| 0 | 分工、预约、合法接触攻击与防重叠 |
| Ⅰ | 更多合法邻近巡逻候选，扩大覆盖半径 |
| Ⅱ | 局部粗网格密度评分，逐病毒核对距离及可见性 |
| Ⅲ | 活跃释放节点局部信号响应增强，仍完整预警和接触 |
| Ⅳ | 按已发现目标区域预约分工，减少多个单位集中同区 |
| Ⅴ | 小地图支路巡逻回退：提前2.8秒提示，现有闲置单位短时15秒派遣后轮换 |
| Ⅵ | 最后观察位置附近限时8秒搜索，失败恢复巡逻 |

总数上限8，T和巨噬各最多4；招募间隔65秒，出生与存活玩家群保持4.5米安全距离。只使用地图免疫入口，无安全入口延期；不外围空降。警戒不直接加伤害、炎症或自动增援数量。

## 本地窗口证据与指标

使用已安装Maker 0.0.36本地预览，并通过原生窗口截图、鼠标键盘操作和GIF录屏验收。测试获取卡牌后仅使用自然移动、原分裂、Tab和真实吸收形成群体，没有直接修改质量或节点状态。每批相关修改后检查预览状态；运行时自动刷新，已停止的会话没有按刷新规则自动复活，后续运行均为已授权的独立试玩。

主要证据：

- `validation/cards-20261011/native/validated-gameplay.gif`：两次真实获取、Ⅰ／Ⅱ警戒、小脑感染及避敌、Tab、免疫分工。约4分钟窗口采样，GIF为约2帧／秒，重复画面合并，非高帧率视频。
- `native/actual-four.png`：4／4群，小脑感染和避敌同时出现。
- `native/fixed-alert-one.png`与`native/fixed-alert-two.png`：能力立即生效、升级说明、暂停和5秒缓冲。
- `native/alert-V-VI-debug-final.gif`、`native/final-V-active.png`：Ⅴ／Ⅵ调试选择与运行；HUD明确显示调试覆盖，获取记录为0。
- `native/final-VI-active.png`：Ⅵ调试下真实灭团结算；不是自然获得六张卡。
- `native-metrics.json`及`native-lua-*.log`：群数、操作、辅助感染、损失、免疫／节点数、炎症、损伤和帧间隔。

无调试覆盖的四群局，观测到3次分裂、1次Tab、小脑辅助完成6个节点、采样时小脑质量损失0，免疫最多8个。约255秒模拟时炎症85.7、损伤27.7（后段Ⅳ为调试覆盖，不能归因于自然卡牌警戒）。这些是一次试玩观测，不代表总体平衡。操作频率可由累计分裂／切换次数除以样本模拟时间计算；未计入持续移动的每次按键。辅助感染是至少一个小脑分群曾参与接触的完成节点，不代表独占贡献。

帧间隔典型约7～9毫秒、部分峰值约20毫秒，来自引擎TimeStep，包含窗口采样／录屏干扰，不等于纯渲染或CPU耗时。早期采样mass字段误读主群质量，最终版本已改为当前群质量；历史日志须以截图或正确字段含义解读。

预览日志持续报告现有`Cube/Day/DaySpecularHDR.dds`缺失及`themis_x64.dll`加载失败；实际窗口正常加载并完成试玩，Maker通用检查因此不能宣称全通过。没有发送故障报告。
