# 补充音效与环境音生成提示词

本清单补充此前已制作的12项音效，不重复要求重做那些文件。共21项：10项优先补充、10项第二批补充、1项循环环境音。每个代码块均可独立复制。本文是制作说明，尚未生成或接入音频。

## 制作方式与统一交付

- **Python合成**：交给能够执行Python的AI，实际计算波形并导出WAV；不是只生成代码，也不是调用AI音效接口。适合短信号与环境底音。
- **AI音效生成**：交给文字转音效工具；更适合膜层、胶质、液体等有机质感。若工具支持参考音频，可附上现有12项中相近的声音以统一风格。
- 单次音效：WAV、48kHz、PCM 16bit、单声道，目标峰值不高于-3dBFS，无削波、无明显前置静音、首尾平滑，不循环。短音效不要响度强压缩。
- 环境音：WAV、48kHz、PCM 16bit、双声道，30秒无缝循环，建议峰值不高于-12dBFS；实际背景音量仍在游戏中调整。
- 建议最终目录：`assets/audio/`。先保留制作源文件与原始导出，不覆盖现有素材。
- AI工具无法精确生成指定长度时，先保留完整动作，再用Python或音频编辑器裁剪、淡出；不得强行切断有效声音。提示词中的频率和分段是制作方向，可为听感微调。
