# 后期游离病毒性能优化

2026-10-17。针对大量游离病毒释放后运行压力显著提升，优化正式平面地图的流场查询、短步移动和密集接触表现。保留全部真实病毒实体、60 Hz 固定步、流场、碰撞、感染贡献、免疫职责与数量预算。

## 瓶颈与实现

`_MoveReleased` 每步为每颗病毒调用一次流场查询。旧 `FlatMapLayout.FlowAt` 每次遍历所有流场和全部路径线段，重新计算固定线段的长度、方向和累计路程。性能采样中这一部分占据主要开销，数量越多，重复工作越明显。

现在为每张地图建立四米网格的流场空间索引。路径线段按流场半宽扩大包围盒后放入可能影响的格子；漩涡按完整外半径登记。查询只检查当前格子内的候选，最终仍用原来的精确距离、侧向衰减、端部衰减、叠加和限速公式。保留原流场顺序及同一路径线段顺序，维持浮点累加与等距时的选择结果。固定长度、方向与累计路程只计算一次，位置与贡献没有量化或插值。

派生索引存放在模块的弱键缓存，不进入地图存档／快照，也不消耗随机数。更换 `map.flows` 数组或改变数量会自动重建；若开发时原地编辑路径点或宽度，应调用 `FlatMapLayout.InvalidateFlowIndex(map)`。速度和方向始终读取当前值。现有流向卡的限时覆盖仍在 `FlatWorldMap.FlowAt` 原入口结算。

`FlatWorldMap.Move` 新增保守快捷路径：整个扫掠圆盘严格处在同一块开放的一米方格内时直接完成原位移。跨格、靠墙、圆角、长位移及非法起点继续使用原精确扫掠与滑动。计算结果与旧实现逐值对照。

`CellContacts.Commit` 保留每一个被接受来源的实际感染贡献。表现层只为最多三个稳定槽位和历史锚点更新记录，原实现却会为整批候选排序、创建记录并计算三角函数。现在完整更新已有槽位／锚点，再挑出最多三个最强有效新来源参与原选槽逻辑；没有接触历史和新接触的细胞立即返回。密集接触下减少大量临时表和被丢弃的表现记录，已有方向、淡出、重入及锚点切换保持一致。

## 验证和边界

入口 `python -B tests/released_performance_regression.py`，证据位于 `validation/released-performance-20261017/`。其中 `baseline/scripts/` 保存本轮开始时的 Core／Game 源码，继承上一版分区驻巡、数值成长和阶段进度修正。

- 三个正式 v5 地图种子，与旧版对照约 8.5 万次流场查询及 3.6 万次移动查询，结果精确相同。覆盖全地图格点、随机点、路径边缘／端部／转折、漩涡、网格边界、不同身体半径，以及宽度失效重建。
- 密集接触对照 360 帧，每帧最多 1200 个来源，包含来源增减、等强排序、中心重叠、完全离开、淡出和重入。完整槽位及锚点状态与旧版相同；另有 21 项既有接触回归。
- 使用真实 120×144 米、960 细胞地图，20 名免疫，分别安排 300／1000／3000／6000 颗游离病毒，以及 3000 颗集中接触的压力场景。每项记录预热后 30 个完整 World 更新步的中位数、P95、最大值、冷启动步和平均进程 CPU 时间；全量玩法／接触状态与随机数指纹必须相同。
- 既有玩法、卡牌、免疫和阶段逻辑回归，以及 Lua 语法、LSP 和差异检查记录在同目录。

地图生成和比较快照的序列化不计入更新耗时；各轮复制同一份未使用的正式地图几何模板，世界、实体、生态、路径缓存、计时和 RNG 各自独立。释放和密集摆放为明确安排的压力条件，不是自然整局难度或真人路线。宿主负载会影响耗时，具体前后数值及重复测量记录以该目录报告为准。

这些结果衡量 Lua 模拟开销，不包含引擎绘制、纹理上传、GPU、原生输入或设备帧率；表现碰撞和可见实体绘制仍会随屏内数量增加。本轮保持已停止的本地预览状态，后期实际帧率与长时游玩由人工复测。
