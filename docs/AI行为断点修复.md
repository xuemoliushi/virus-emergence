# AI 行为断点修复（2026-10-13）

本轮范围是 AI 审查中列出的三个行为断点：追踪失忆缓冲、清理残骸解除掩护、留守失效释放自主性。局部信号场、吞噬负载、探索与自主施放技能未在本轮实现。

后续四类规则已实现并完成非实机验收，见 `四类涌现规则.md`。上述“未实现”描述保留为三项修复阶段的范围记录；目前已有局部信号、负载/识别、卡牌门控的补充/探索和组织防御。自动分裂与自主施放技能仍未加入。

| 改动 | 无机制卡状态 | 机制卡相关行为 |
| --- | --- | --- |
| 首次发现与已锁定追踪分离 | 基础免疫生效：首次发现范围保持原值；已锁定、直线可见目标在额外 1.8 米缓冲圈内继续追踪。超过圈、隐藏或遮挡立即停止实时坐标追踪。 | 伪装仍只降低首次发现，不抹除既有锁定；警戒 III 活跃节点范围加成保留。警戒 VI 的旧位置搜索保持等级门槛，低警戒失锁后恢复巡逻。 |
| 清理残骸消除掩护 | 原有巨噬清理继续只执行一次；DEAD 细胞终态、炎症、节点病程和质量账本保持原含义。 | 仅拥有残骸伪装时，未清理且邻近的残骸提供掩护；最后一处掩护被清理当步即解除伪装及停留进度，其他未清理残骸仍可提供掩护。 |
| 留守解除 | 没有集群调度时不产生群指令；没有分群小脑时不会获得自主感染、逃逸、自动分裂或自动用技能。 | 留守遇到局部危险，或其原感染目标不再为 HEALTHY/EXPOSED、被移除时，清除整个指令和旧驱动速度。在同一真实固定步的小脑决策前解除，已解锁小脑的群重新选靶或逃逸。安全的无目标留守仍等待；集合指令保持玩家意图优先，Tab 接管、锚定、藏身、冲刺的优先关系保留。 |

实现复用当前唯一世界和实体表：`ImmuneSystem` 继续负责预警、接触攻击和冷却，`AbilityRuntime` 复用 `_immuneClearedDebris` 的实际清理事实，小脑恢复仍通过原 `IsAutonomous` 解锁判断。留守解除产生 `group_command_released` 事件，携带群 ID 与 `danger`/`target_invalid` 原因；不产生额外病毒或移除能力成本。

卡面描述同步补充“未清理残骸”及“留守遇险或目标失效解除”，稀有度、卡池和解锁依赖不变。
