## 一、本次机制变化：未受控群不再只是待命

所有存活、非隐藏、**当前未受玩家控制**的群都执行自主行为，包括玩家切离后的主群。当前受控群仍完全由玩家操作：AI 不抢移动方向、不替玩家选靶、不自动分离。Tab 或群列表切换后，新受控群立即退出自主状态，原受控群进入自主状态。

自主优先级为：

1. **躲避免疫威胁**：只感知附近、合法且无墙遮挡的免疫实体，使用有限方向探测选择更安全的局部逃逸方向。评估路径风险，并把静止作为基线，不为制造位移而主动走向更危险方向。
2. **主动感染**：安全时寻找约 6 米内可直接接近的 `HEALTHY / EXPOSED` 细胞，保留目标并用预约惩罚分散群体，避免所有群反复抢同一目标。实际接触后才累积感染，不远程感染、不直接改细胞状态。
3. **收集与巡游**：无安全感染目标时，尝试接近约 2.4 米内的真实游离病毒，并通过原吸收机制增加质量；没有合适目标则局部巡游。
4. **自动分离**：达到下节规模、成熟时间和安全条件时，以真实质量成本生成新的自主分群。

AI 只产生意图；世界仍统一处理惯性、组织流、弹射、地图扫掠和实际位移，没有增加第二套模拟更新。自主感染仍计为玩家群贡献，不冒充游离病毒独立感染，不替玩家完成释放病毒专属来源任务。

**行为边界：** 这是局部直达及有限方向避障，不是全图寻路。躲避不保证解除免疫锁定或必然逃脱；免疫追踪、蓄力、攻击和真实清除继续生效。

## 二、自动分离与无限群数

### 2.1 当前数值与门控

| 项目 | 当前默认值或规则 |
|---|---|
| 存活群数量 | **不设数量上限**；手动和自动均无六群门控，没有前 N 群截断 |
| 自动分离质量 | `autonomy.splitMass = 48`，包含恰好 48 |
| 自动成熟 / 冷却 | `autonomy.splitCooldown = 8` 秒，**每群独立**，仅自主模拟推进时递减 |
| 自动分离安全条件 | 非受控、存活、非隐藏；无弹射、无合并保护、非逃逸、附近无可见危险 |
| 手动最低质量 | `splitMinMass = 12`，保留 |
| 手动分离冷却 | `Gameplay.splitCooldown = 8` 秒，保留世界级玩家冷却 |
| 分离损耗 | 当前质量的 10%，向下取整，至少损耗 1 个 |
| 子群分配 | 损耗后质量约一半，向下取整；源群、子群均至少剩余 1 个 |
| 合并保护 | 2 秒，保留；自动分离还需等待自己的 8 秒成熟 / 冷却 |

新群出生即有 8 秒自主成熟时间。每次手动或自动分离后，源群和子群的自主冷却都重置为 8 秒；玩家接管期间该群的自主时钟不推进。暂停也不会补跑。**达到 48 并不代表立即无条件分离**：危险、保护、弹射或冷却会延期。

自动分离不消耗或重置玩家的世界级手动冷却，不切换控制、不清掉玩家移动输入。每固定步对原群 ID 快照排序，每个原群最多自动分离一次，新生群不会在同一步递归分离。

```text
损耗 = max(1, floor(质量 × 0.10))
子群质量 = floor((质量 - 损耗) × 0.5)
源群质量 = 质量 - 损耗 - 子群质量

例如：48 → 损耗 4 → 源群 22 + 子群 22
```

手动与自动共用 `_SplitSwarm` 的损耗、真实粒子归属、反冲、弹射和保护逻辑，不存在免费增殖。分离首帧保持原粒子位置，仅改变归属；下一固定步更新为新阵型，沿用原手动分离的“不瞬移粒子”政策。

### 2.2 合并与控制

- 两个自主群不再隐式互相牵引、刚分开又主动归并。
- 逃逸行为优先，不会被合并牵引打断。
- 玩家受控群与非逃逸自主群**真实接触**时，仍可回收正在寻靶、感染或收集的群。
- 未接触时的远距吸引不会打断这些自主目标；无远程召回。
- 主群接任、当前群消亡后自动选择有效幸存群、旧触控捕获清理等已有规则保留。

## 五、守恒、确定性与性能边界

```text
initialMass + totalReleased - totalKilled - totalLost - splitCost == Counts().virus
Counts().virus == Counts().controlled + Counts().released
#world.viruses == Counts().controlled
```

本轮真实修复了多个成熟群同一步自动分离受数组顺序影响的问题：按 ID 排序后，子群 ID、事件顺序、弹射及后续位置稳定。另补逃逸静止基线 / 路径安全，以及玩家真实接触回收忙碌自主群的兼容性。

为无数量上限场景减少重复扫描：合并候选用空间桶及相邻九桶，粒子用群 ID 映射单遍更新。独立差分检查覆盖 120 个群对夹具的 36,939 个有序候选和 120 个粒子夹具的 363,774 个位置，分别保持原同规则候选顺序和位置逐位一致。

**无限群数不等于无界资源保证。** 没有群数截断，但同点密集群对仍可能达到 O(n²)，动态 UI 高水位槽仍占内存，实体与 AI 也随数量增长。40 群压力和 180 秒模拟是有限验证，不代表任意多群都保持性能；本轮未加入隐藏上限或新的数量限制。

## 一、给协作者的简要说明

本轮把病毒群玩法从“主要依靠近距自动收集、最多主群加一个分群”，扩展为：

1. 玩家可以按 **E** 或点击 **“吸附 E”**，立即把当前受控群附近符合条件的游离病毒收入该群。
2. 收集后群体质量增加，**真实接触感染功率继续随规模增长**，不再在旧倍率上限处停止加速。
3. 达到质量要求后可重复分离，默认最多 **6 个存活群体，包含主群**。
4. 按 **空格 / 2** 或点击分离按钮创建新分群；按 **Tab** 循环切群，或直接点击群列表选择目标。
5. 多群仍遵守原有分离损耗、冷却、近距合并、免疫清除和胜败规则。没有新增免费增殖、远程召回或死群复活。

### 操作表

| 操作 | 按钮 | 快捷键 | 说明 |
|---|---|---|---|
| 主动吸附 | 吸附 E | `E` | 立即收入当前群附近可吸附的游离病毒，无吸附冷却 |
| 分离 | 分离 空格 / 2 | `Space` 或 `2` | 两个快捷键是同一操作，继续使用原损耗与冷却 |
| 循环切群 | 切群 Tab | `Tab` | 按存活群数组顺序循环，最后一群回到第一群 |
| 指定切群 | 群列表中的群按钮 | 无新增数字直选 | 点击实时群 ID；当前群高亮 |

这些动作只在已经开始、未暂停、未结算的细胞玩法中执行。观察、转场、说明弹窗和失焦暂停期间不能绕过门控。快捷键忽略自动重复的 `KeyDown`，避免长按时连续触发。

## 二、机制细节与数值

### 2.1 主动吸附：转移个体，不制造个体

吸附中心是 **当前受控群**，不固定是主群。按下时取一次候选快照：

```text
吸附距离 = 当前群实际半径 + activeAbsorptionExtra
activeAbsorptionExtra = 1.8 米
```

候选必须同时满足：

- 当前群存在、质量大于 0，且没有隐藏。
- 游离个体仍存活，未被吸收或清除，且 `age < lifetime`。
- 个体在本次按下时的吸附距离以内；恰好在边缘允许吸附。
- 个体到群中心之间，按个体半径进行的完整直线扫掠位于合法组织地图内。

地图检查复用 `RespiratoryMap:_Sweep`，而不是仅检查终点，或用能够沿墙滑移的 `Map:Move` 代替直线路径检查。因此，隔着组织空隙、地图外或极细枝间间隙的病毒不会穿墙吸入。

成功吸附时：

1. 游离记录置为 `ABSORBED`。
2. 当前群质量增加 1，添加该群的粒子表示。
3. 沿用来源个体的半径、变体和视觉相位，不额外随机生成外观。
4. 更新群阵型半径和粒子位置，累计 `totalAbsorbed`。
5. 发出单个吸附事件及本次吸附脉冲；界面立即刷新数量和倍率。

**一次操作不会连锁扩大收集范围。** 即使前几个个体增加了半径，本次只处理最初范围快照。下一次按 E 才使用新半径。

原有近距自动吸收仍保留，并复用个体转移逻辑。没有目标时返回 0 并显示提示；不能恢复过寿命个体、终态个体或已经消亡的群。

### 2.2 群越大，真实感染越快

群体规模倍率统一由以下函数计算，HUD 显示与实际感染使用同一来源：

```lua
GroupInfectionMultiplier(swarm) = sqrt(swarm.mass / densityReference)
densityReference = 10
```

| 群质量 | 规模倍率，约值 |
|---:|---:|
| 10 | ×1.00 |
| 30 | ×1.73 |
| 40 | ×2.00 |
| 90 | ×3.00 |
| 160 | ×4.00 |
| 640 | ×8.00 |

实际功率还乘以真实接触距离系数；**离开细胞不会凭空感染**。本轮去掉旧“单群倍率最多 2”和“全部来源总功率最多 3”对群增长的封顶：

```text
群功率 = Σ(各合格接触群的距离系数 × 规模倍率)
计入的游离功率 = min(3, 游离病毒接触功率)
总功率 = 群功率 + 计入的游离功率
新增感染进度 = 接触步长 × 总功率 / infectionSeconds
```

只有游离病毒自身功率继续封顶为 3，群贡献不会被其挤掉。群与游离的贡献分别按实际计入功率准确累计，保留原感染归因逻辑。

- 感染按真实 `1/60` 秒移动步累积，原 `0.5` 秒病程结算仍保留。
- 未受控群可以延续已经接触的目标，不能自行开启新的感染目标。
- 分离复制既有接触目标，合并取目标集合并集，不把多群改成自动寻路感染 AI。
- 潜伏、产毒、耗竭、死亡、释放批次、炎症和免疫规则未在本轮重做。

倍率是规模因子，不是保证“若干秒完成感染”的承诺。距离、多个来源、免疫清除和病程结算都会影响实际结果。大群原有的移动速度代价仍然存在。

### 2.3 多次分离：默认六群，保留成本

分离门控集中在 `SwarmWorld:CanSplit()`，按钮禁用和实际执行共用同一判断：

| 参数 | 当前值 | 本轮处理 |
|---|---:|---|
| `maxSwarms` | 6 | 新增，计算主群与全部分群合计 |
| `splitMinMass` | 12 | 保留，检查当前受控群质量 |
| `splitCooldown` | 8 秒 | 保留，为世界级分离冷却 |
| `splitCostFraction` | 0.10 | 保留，向下取整且至少损耗 1 |
| `splitFraction` | 0.5 | 保留，损耗后约一半转给新群 |
| `mergeGraceSeconds` | 2 秒 | 保留，分离后暂不立即合并 |

```text
损耗 = max(1, floor(当前质量 × 0.10))
新群质量 = floor((当前质量 - 损耗) × 0.5)
原群剩余 = 当前质量 - 损耗 - 新群质量
```

两方必须至少剩余 1。粒子通过改变 `swarmId` 转移归属，成本粒子删除并记入 `splitCost`，不会凭空增加总质量。新群沿最近移动方向弹出，原群保留反冲；弹射缩放使用分离前质量快照。

冷却未结束、达到六群、质量不足、隐藏或没有活群时拒绝分离。修正了恰好推进八秒后浮点残差可能继续阻止分离的边缘情况。

### 2.4 切群、消亡与合并

必须区分两个概念：

- `world.player` / `currentControlledSwarmId`：**当前受控群**。
- `world:MainSwarm()` / `isMainSwarm`：**主群身份**。

切换控制并不把分群改名为主群。主群消亡后才由幸存群接任主群；当前受控群消亡或被合并时，控制指向有效幸存群。所有群消亡时控制 ID 清零，不允许通过吸附复活。

切换、分离和自然控制变化会清理旧移动输入及摇杆捕获。特别修复了旧手指尚未抬起、群已消亡时，后续 `PointerMove` 可能推动新群的问题；新群需要一次新的有效按下才能接管触控移动。

多群合并不再把整个群数组重置成一个主群：

- 只处理合法近距、无保护期、非隐藏且直线路径畅通的群对。
- 已接触群对优先，再按归一化间距、规范化 ID 排序；防止远群先占用近群，导致已经重叠的群无法合并。
- 每个群每移动步最多参与一次群对处理。
- 有主群参与时保留主群 ID。
- 两分群合并时，若当前受控群在其中，保留该受控 ID；否则保留较低 ID。
- 控制对象不在合并对中时，不抢走控制。
- 只移除被合并方，其余远处分群及各自粒子、接触目标不受影响。

近距吸引和接触合并仍保留；没有添加远程召回按钮。

## 四、质量守恒与回归中修复的问题

活病毒总数仍满足：

```text
initialMass + totalReleased - totalKilled - totalLost - splitCost
    == Counts().virus

Counts().virus == Counts().controlled + Counts().released
#world.viruses == Counts().controlled
```

主动吸附改变“游离 / 群内”的分类，不改变活病毒总数。分离只扣成本；合并只是归属转移。

本轮验证中实际修复了：

1. **真实 Button 没有 `GetText()`**：改用 `btn.props.text` 比较，再调用 `SetText()`，不修改引擎库。
2. **自然清群后触控捕获残留**：SimState 和 HUD 联动清理，覆盖事件早于 HUD 更新的情况。
3. **多群合并饥饿**：已经重叠的群对优先，远距吸引不能先占用该群。
4. **冷却/范围浮点边缘**：八秒冷却边界和恰好吸附距离边界均有回归用例。
5. **验收夹具点击肺透明缝隙**：只修测试坐标，查询原 `LungMasks.Contains` 内部且 `UI.FindWidgetAt` 真正命中的位置；未放宽生产蒙版或改业务点击规则。
