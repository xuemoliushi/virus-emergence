# R03 局部细胞因子与干扰素场

**日期：** 2026-10-04  
**类型：** 机制性修改  
**状态：** 已构建通过

---

## 目标

把"炎症"和"干扰素"从区域级标量，拆成有释放源、衰减、采样点间扩散、区域间扩散、相互抑制的局部信号场。感染、免疫、损伤不再同步发生，而是被信号场拉开时间差和空间差。保留聚合值作为区域间计算和性能兜底。

---

## 实现内容

### 1. Config.CytokineField（Config.lua）

新增配置块，定义 5 个采样点坐标（与 CellView 重点细胞 focusSpots 对应，复用布局）以及干扰素（ifn）和促炎因子（pro）的全部参数：

| 参数类 | 关键参数 |
|--------|----------|
| IFN | `releasePerInfected`、`latencyMul`、`decay`、`diffuse`、`regionDiffuse`、`protectMax`、`protectVsAttach`、`recruitSuppress` |
| PRO | `releasePerDead/Kill/Debris/Damage`、`decay`、`damageDecayMul`、`diffuse`、`regionDiffuse`、`damageThresh`、`damageRate`、`ifnSuppress`、`recruitBoost` |

### 2. SimState.lua — region 初始化

每个区域新增 `cytokines` 字段：5 个采样点，每点持有 `{ ifn = 0, pro = 0 }`。

### 3. SimState.TickCytokineField（SimState.lua）

新增方法，每 tick 对每区域的 5 个采样点执行：

1. **释放**：感染细胞向各点释放 IFN（潜伏期倍率减弱）；死亡细胞、免疫杀伤、碎片（dead）、损伤向各点释放 PRO
2. **采样点间扩散**：相邻两点取平均，按扩散系数交换
3. **跨区域扩散**：与相邻区域平均值按 regionDiffuse 系数交换
4. **相互抑制**：高 PRO 加速 IFN 流失（促炎削弱保护）
5. **衰减**：IFN 和 PRO 各自按比例衰减，PRO 在高损伤时衰减变慢（`damageDecayMul`）
6. **局部损伤**：PRO 超过 `damageThresh` 的超量部分以 `damageRate` 速率累积 `r.damage`
7. **钳制**：IFN 上限 5.0，PRO 上限 8.0，防止数值爆炸
8. **写出聚合值**：`r.cytokineIfnAvg` 和 `r.cytokineProAvg` 供 TickRegion / TickImmuneAgents 读取

在 `Tick()` 第3步加入调用：
```
self:TickCytokineField(r)
```

### 4. SimState.TickRegion — 感染计算（SimState.lua）

感染压力乘以干扰素保护系数，高附着毒株保护效果减弱：

```lua
local protectEff = protectMax * (1 - att * (1 - protectVsAttach))
local ifnProtect = min(protectEff, ifnAvg / (ifnAvg + 1.0))
infectPressure = infectPressure * (1 - ifnProtect)
```

### 5. CellView.DrawWorld — 场视觉（CellView.lua）

在病毒粒子之上、免疫细胞之下，对每个采样点绘制：

- **干扰素**：淡蓝紫发光圈（`{ 120, 160, 255 }`），ifn 值 0→5 时半径 20→80px，透明度 0.08→0.26
- **促炎因子**：橙红热晕（`{ 255, 120, 50 }`），pro 值 0→8 时半径 15→70px，透明度 0.06→0.28

## 涌现效果

- **保护圈**：感染细胞周围 IFN 积累，细胞层出现蓝紫光晕，感染波向外扩展时被拖慢；高附着毒株更容易突破
- **免疫延迟**：感染初期 IFN 抑制促炎招募，促炎积累缓慢，免疫到达存在时间差
- **免疫风暴**：免疫活动大量释放 PRO，PRO 超过损伤阈值后直接累积 `r.damage`，损伤又持续释放 PRO，正反馈失控
- **炎症滞留**：病毒下降后，碎片（r.dead）和损伤持续释放 PRO，衰减因高损伤变慢，炎症不立即消退
- **场竞争**：同一区域内 IFN 和 PRO 浓度分布不同，高 PRO 区域削弱 IFN 保护

---

## 性能约束

- 5 个采样点，每区域每 tick O(5) 计算，开销极低
- 跨区域扩散用相邻区域平均值，不逐采样点计算
- 聚合值 `cytokineIfnAvg/cytokineProAvg` 承担区域级计算，场值只影响局部精度
