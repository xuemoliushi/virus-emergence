## 二、未实现、暂缓及部分实现清单

### 未实现或明确暂缓

1. **正式机制卡系统**：事件触发、随机三选一、卡牌获取、卡牌使用/冷却与三种卡牌效果都未实现。仅有三条不可用占位和说明 UI。文档第 8 章虽然详述卡牌，第 16 章仍把三张卡与多个事件列为第二优先级；当前按用户确认保留占位，不视为漏做已确定的首发能力。
2. **随机地图生成**：无局部组织程序生成、Poisson Disk、随机细胞簇/密度/流道/免疫入口或失败后重生成。现状是固定地图，72 个普通细胞锚点；seed 只影响外观参数。
3. **高产细胞、警戒细胞与其他特殊细胞**：当前普通细胞的 `variant` 是外观变体，不代表特殊细胞类型，也没有这些类型专有生产/警戒行为。
4. **三类完整流区**：有固定通道和 normal/fast 流速差别及组织内弱漂移；没有独立的紊流区、旋转涡流或完整的“安全区/高风险路线”随机生成。
5. **10–15 分钟局长与平衡**：配置中有 `targetDurationMin=600`、`targetDurationMax=900` 目标值，但它们不触发计时胜利，也不保证实际局长。炎症、损伤、呼吸阈值和感染/免疫数值仍是待调初值；尚无完整玩家操作的一局长时胜败路线验证。
6. **残骸移动惩罚、复杂免疫 AI、抗体/基因/遗传、多器官精确模型、联网、复杂卡牌商店**：没有实现；其中多项在原规格第三优先级明确暂缓。

### 部分实现或不能按规格强度宣称

- 地图空间可达性、碰撞与开局点检查已经有固定地图 `Map:Verify` 和有限种子/栅格测试；但没有随机地图，因此原规格“普通细胞 80% 可达、每局重掷种子直至合格”等完整验收流程未实现。
- 细胞/病毒/免疫的状态和数据模型分散在多个 Lua 模块中，功能字段存在，但不是按第 11、14 章建议的数据类逐项复制。
- 免疫确有巨噬与 T 细胞及预警/追击/接触攻击，但不是复杂寻路或完整免疫生态系统。
- 开局和观察 UI 已按后续要求更改为小鼠/解剖/肺叠图流程，不再是规格第 4 章描述的单独简化地图选择弹层；实际三起点与区域信息仍保留。

### 对原规格的明确覆盖/改写

- 原文分裂方向是鼠标方向（第 6.3 节）；后续要求已改为**最近一次 WASD/方向键/摇杆移动方向**。
- 原文仅泛称起始区域选择；后续要求改为**小鼠外观 → 完整解剖叠肺 → 点击真实肺轮廓放大 → 三个器官蒙版选区**。
- 原文对组织流视觉建议避免明显蓝色水流；后续为了可辨识度增强了青蓝色真实流道带和箭头。组织流机制仍为简单程序化向量场，不是流体力学。
- 之前选区蒙版 alpha 再次按用户要求提高；当前数值以本节列出的最新版为准。
