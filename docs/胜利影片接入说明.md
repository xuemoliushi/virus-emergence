已接入 2026-10-17 的 90 秒修订版 5（中英双语字幕、英文旁白及配乐）：60–87 秒使用已确认的城市至地球 v2，低空穿云在 65.45 秒结束，地球拉远的接点速度不归零。59–61.3 秒移除有矩形硬边的云层贴片，只使用全屏程序柔雾。路口仍为 46–60 秒，14 秒、1 倍速度；去掉该镜头的重复脚步和环境擦响，保留配乐与旁白，已确认台词及字幕时序不变。胜利判定继续来自 `SimState:FinishRun("victory")`，不更改通关条件。

## 2026-10-19 游戏到影片的衔接调整

胜利后不显示胜利标题、统计或按钮面板。此次只调整游戏进入影片的画面和混音，沿用修订版 5 片源：

1. 前 0.55 秒淡出游戏操作界面，屏蔽操作，停止教程提示。视频同时异步准备，初始音量与图层透明度均为 0。
2. 微观镜头在 2.6 秒内拉远至原缩放的 72%。从当前画面中选取最近的感染细胞（距离不超过 3 米），缓缓将其靠近镜头中心；没有附近感染细胞则保持原焦点。HUD 消失时保留原镜头避让区域，避免构图跳动，不改模拟实体的位置。
3. 0.55 秒后若播放器就绪，跳到影片原时间 2.1 秒，越过已有黑场和暗部起始段。等待实际播放时钟超过该时间至少 0.03 秒，再开始叠化；仅 Seek 成功或 onPlay 回调不算真实起播。片源文件仍为 90 秒，原有旁白、字幕与后续镜头保持音画同步。
4. 保留微观场景作为底层，向正在拉远的鸟近景做 1.8 秒平滑叠化，不增加第二段黑场。图层透明度与配乐交叉渐变均跟随视频真实时钟；解码停顿时混合比例保持。影片完全显出后才隐藏微观场景。继续使用官方 `Video.VideoPlayer`，保留 16:9 比例，单独绘制画面外的黑边，避免多个全屏黑底叠加造成亮度下沉。
5. 心跳/追逐层在 0.7 秒内淡出，零散音效在 1.1 秒内淡出，环境底声在 1.8 秒内淡出。游戏底乐保留到影片真正起播，再使用余弦/正弦等功率曲线与影片配乐交叉渐变。慢加载或自动播放受阻时保留微观画面与游戏底乐，显示准备提示或播放按钮；播放错误则停止旧声音并提供重试/返回菜单。
6. 影片结束或长按退出后仍按原有流程淡黑返回主菜单；再次点击“开始”建立新一局。重置时恢复 HUD 透明度和镜头，不留隐藏状态。

正常播放不显示右上角“跳过影片”按钮。像新手教程一样，持续按住 **Esc 1.2 秒**退出：只在按住期间显示右上角金色进度与百分比，画面逐渐变暗；松开、窗口失焦或最小化立即清零，短按和多次分段按住均不退出。必须在结局等待/播放阶段新按下 Esc，从游戏或教程带入的按住状态不会触发。按满后沿用原有画面和声音淡出返回主菜单，保留变暗遮罩直到淡出盖住画面，避免闪亮一帧。

浏览器拦截自动播放时仍提供“播放影片”按钮和空格/回车操作。加载失败和等待超时提供中央“重试播放”和“返回主菜单”入口，也支持长按 Esc；正常播放没有返回按钮。失败结算保留原有行为。

### Windows 本地快速查看

本地窗口预加载完成后，在主菜单或游戏中按 **F8**，保留 3 秒游戏画面与底乐，再调用真实 `SimState:FinishRun("victory")` 播放衔接。影片期间按 F8 可从新一局重新演示。这是标记为 `debugRun` 的预览局，不代表自然通关；Web 不开放此快捷键。运行时若不支持影片解码，会显示原有的播放错误界面，需要以实际窗口证据判断是否可播放。
