# 吸附位置与尺寸修正

2026-10-10。本轮落实最新的三项纠正，保留此前出芽、颗粒、免疫追踪和组织流调整。

| 项目 | 现在的行为 |
|---|---|
| 吸附位置 | 每次真实进入接触时读取病毒群当前方向；连续接触期间固定。离开后沿用原缓慢淡出，再次进入立即重算，即使旧淡出未结束或渲染漏过离开帧 |
| 局部感染色斑 | 与本次吸附共用细胞局部膜锚点，重新接触时重置位置。连续接触期间不沿膜滑动，随细胞旋转。进入潜伏、产毒和耗竭后保留最后一次位置 |
| 吸附病毒大小 | 玩家群使用实际单颗病毒半径，游离病毒使用对应实体半径；缺来源时使用原配置。按原图有效前景换算，显示直径为真实半径的两倍乘镜头比例，不随细胞尺寸额外放大 |

接触段信息仅为表现元数据，记录在 `CellContacts` 的真实接受分支。局部色斑继续使用原色块及裁剪图集；其膜锚点与病毒一致，原图层比例保留。病毒和亮斑使用同一尺寸与姿态，亮斑按实际膜轮廓重新裁剪并缓存。死亡、退出及世界切换释放记录；初始感染但没有真实接触的细胞不补造色斑。
