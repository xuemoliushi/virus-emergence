# 病毒涌现模拟游戏玩法规格

## 1. 项目定位

本项目是一款 2D 俯视视角的多尺度病毒涌现模拟游戏。

玩家控制的是流感病毒群体的行为倾向，而不是逐个操控病毒颗粒。玩家通过改变病毒群体的局部策略，观察病毒、组织细胞、免疫细胞和小鼠个体状态之间如何相互影响。

游戏的核心不是预设动画，而是：

```text
玩家改变病毒群体策略
→ 病毒在组织中的分布发生变化
→ 细胞感染和死亡发生变化
→ 炎症与免疫响应出现
→ 组织损伤变化
→ 小鼠症状变化
→ 小鼠康复或死亡
```

本项目是游戏化的涌现模拟，不是科研级小鼠病程预测系统。

---

## 2. 核心设计原则

### 2.1 玩家不能直接决定结果

玩家不能直接执行以下操作：

- 点击某个细胞并强制感染。
- 点击某个免疫细胞并立即消灭。
- 直接制造小鼠死亡。
- 直接把病毒传送到其他区域。

玩家只能改变某个区域内病毒群体的行为倾向。感染、免疫和小鼠结局由系统持续计算。

### 2.2 表现层必须由模拟事件驱动

所有关键动画都必须对应模拟事件。

例如：

```text
模拟事件：病毒成功附着
表现：病毒停留在细胞膜边缘，播放接触亮点

模拟事件：感染成功
表现：病毒进入细胞，细胞内部出现暖色颗粒

模拟事件：病毒释放
表现：病毒从感染细胞膜边缘出芽并离开

模拟事件：免疫清除
表现：病毒粒子减少，感染细胞亮度下降
```

不能让画面中的动画自行播放并与后台状态无关。

### 2.3 视觉粒子不是实际计数单位

后台可以计算抽象病毒量，例如 `virusLoad = 120`。

画面中不需要显示120个病毒对象，可以根据病毒量显示3～30个代表性病毒粒子。

```text
后台病毒量：低
画面病毒粒子：3～5个

后台病毒量：中
画面病毒粒子：8～15个

后台病毒量：高
画面病毒粒子：20～30个
```

视觉数量必须随着后台病毒量变化，但不要求一一对应。

## 3. 一局游戏

### 3.1 推荐时长

一局游戏持续约5～8分钟。

游戏时间可以压缩现实病程。不要把真实的一天直接等同于游戏中的一天。

### 3.2 游戏开始

初始状态：

- 小鼠整体健康。
- 一个组织区域中有少量初始病毒。
- 其他区域可能存在少量或没有病毒。
- 免疫压力较低。
- 组织损伤较低。
- 小鼠没有明显症状。

### 3.3 游戏流程

```text
开始
→ 病毒进入初始组织区域
→ 玩家观察组织状态
→ 玩家选择病毒策略
→ 病毒感染局部细胞
→ 感染细胞产生新病毒
→ 病毒向相邻区域扩散
→ 炎症逐渐增强
→ 免疫细胞延迟进入
→ 病毒和免疫系统互相影响
→ 组织损伤累积或恢复
→ 小鼠康复或死亡
```

### 3.4 游戏结局

首版必须支持两个主要结局：

#### 康复

满足以下条件：

- 病毒量持续低于清除阈值。
- 没有新的大规模感染。
- 组织损伤没有达到致命阈值。
- 小鼠状态持续一段时间稳定改善。

#### 死亡

满足以下任一条件：

- 组织损伤超过致命阈值。
- 呼吸状态持续低于最低值。
- 小鼠整体健康值降至0。
- 病毒和炎症长期维持在高水平。

小鼠不会因为病毒量刚刚下降就立即康复。病毒被压制后，炎症和组织损伤仍然需要时间恢复。

## 4. 三个观察尺度

游戏包含三个观察尺度：

```text
Scale 0：小鼠个体层
Scale 1：组织层
Scale 2：细胞层
```

### 4.1 小鼠个体层

小鼠层用于观察宏观病程，不进行细胞级操作。

显示：

- 小鼠当前状态。
- 活动量。
- 呼吸状态。
- 鼻部分泌物。
- 体温趋势。
- 体重趋势。
- 病毒载量。
- 炎症水平。
- 组织损伤。
- 整体健康。

小鼠状态：

```text
健康
早期感染
中度感染
重症
康复
死亡
```

视觉表现：

- 健康：活动正常，姿势自然。
- 早期感染：活动略微下降，鼻部有轻微分泌物。
- 中度感染：身体蜷缩，活动减少，呼吸加快。
- 重症：低伏、虚弱、呼吸困难。
- 康复：姿势和活动逐渐恢复。
- 死亡：安静躺下，非血腥表现。

### 4.2 组织层

组织层是主要的策略操作层。

组织层不是：

- 细胞横切面。
- 培养皿。
- 圆形竞技场。
- 一堵密集的细胞墙。
- 一张包含所有器官的解剖图。

组织层是：

> 从正上方观察小鼠呼吸道内部的一片连续微观组织区域。

组织层画面包含：

- 深色组织基底。
- 少量细丝与纤维。
- 半透明流体通道。
- 稀疏颗粒。
- 病毒感染热点。
- 免疫活动区域。
- 组织损伤区域。

组织层划分为4个相邻区域：

```text
[A 起始区] —— [B 通道区]
     │              │
[C 易感区] —— [D 高监视区]
```

四个区域不是四个独立房间，而是同一片组织中的四个计算区域。

组织层显示：

- 各区域病毒活动强度。
- 各区域感染强度。
- 各区域免疫压力。
- 各区域组织损伤。
- 病毒沿组织通道的扩散方向。
- 当前玩家选中的区域。

### 4.3 细胞层

细胞层是组织层中某一个区域的局部观察窗口。

细胞层用于观察：

- 病毒沿微小流体通道漂移。
- 病毒接触细胞膜。
- 病毒附着或失败离开。
- 病毒进入细胞。
- 感染细胞内部产生暖色颗粒。
- 病毒从感染细胞边缘释放。
- 巨噬细胞清除部分病毒。
- T细胞接触感染细胞。
- 感染细胞逐渐受损或被清除。

细胞层不是一个完整的显微镜真实视野，而是当前区域状态的代表性可视化。

## 5. 鼠标滚轮与视图切换

### 5.1 基本规则

```text
滚轮向上：放大
滚轮向下：缩小
```

尺度变化：

```text
小鼠层
→ 组织层
→ 细胞层
```

### 5.2 状态保持

切换视图时必须保留：

- 当前选中的组织区域。
- 当前区域的病毒量。
- 当前区域的感染状态。
- 当前区域的免疫压力。
- 当前区域的组织损伤。
- 当前正在播放或即将播放的事件。

进入细胞层时，必须进入玩家刚才选中的区域，而不是随机生成另一个区域。

### 5.3 细胞层缩略图

细胞层右上角或左上角保留一个极简组织缩略图。

缩略图只显示：

- 四个区域。
- 各区域感染强度。
- 各区域免疫压力。
- 当前所在区域。

缩略图不显示复杂细胞和大量细节，只帮助玩家理解其他区域正在发生什么。

玩家在细胞层主要观察当前区域，不直接操作其他区域。

## 6. 组织区域设计

### 6.1 区域数据

每个区域至少包含：

```text
RegionState
- id
- name
- neighbors
- areaType
- susceptibleCells
- infectedCells
- deadCells
- virusLoad
- inflammation
- immunePressure
- tissueDamage
- fluidSpeed
- fluidDirection
- immuneArrivalDelay
- selectedStrategy
- strategyRemainingTime
- strategyCooldown
```

### 6.2 四个区域的初始设定

以下是游戏参数，不代表真实实验数据。

#### A：起始区

特点：

- 初始有少量病毒。
- 易感细胞数量中等。
- 免疫压力较低。
- 流体速度中等。

视觉反馈：

- 少量暖色病毒点。
- 少量绿色健康细胞。
- 几乎没有冷色免疫信号。

玩法意义：

- 适合建立初始感染。
- 适合测试聚集或扩增。
- 是玩家最早观察的区域。

#### B：通道区

特点：

- 流体速度较高。
- 病毒容易通过。
- 病毒也容易流失到相邻区域。
- 易感细胞数量中等。

视觉反馈：

- 背景中的流体通道较明显。
- 病毒粒子移动速度较快。
- 病毒轨迹更长。

玩法意义：

- 聚集可以减少病毒流失。
- 扩增可能快速产生病毒，但也容易沿通道扩散。
- 适合建立跨区域感染。

#### C：易感区

特点：

- 健康细胞数量较多。
- 初始病毒量较低。
- 免疫压力较低。
- 流体速度较慢。

视觉反馈：

- 健康绿色细胞和绿色活动较明显。
- 暖色病毒较少。
- 冷色免疫信号较少。

玩法意义：

- 适合病毒建立新的感染点。
- 如果病毒成功到达，可能出现较强的正反馈。
- 玩家需要先让病毒自然扩散或从相邻区域进入。

#### D：高监视区

特点：

- 初始免疫压力较高。
- 免疫细胞较早到达。
- 易感细胞数量中等。
- 流体速度较低。

视觉反馈：

- 冷青色信号较多。
- 偶尔可以看到免疫细胞。
- 病毒粒子容易减少。

玩法意义：

- 不适合直接使用扩增。
- 聚集可能带来较高感染收益，也可能被集中清除。
- 隐匿可能延缓免疫发现，但复制速度会变慢。

### 6.3 区域反馈方式

不要只给玩家隐藏数值。使用以下组合：

```text
画面线索
+ 鼠标悬停说明
+ 简化状态图标
+ 小范围数值或等级
```

示例：

```text
B 通道区
流动：强
免疫活动：低
提示：病毒容易经过，也容易随流动离开。
```

区域显示等级：

```text
病毒活动：低 / 中 / 高
感染程度：低 / 中 / 高
免疫压力：低 / 中 / 高
组织损伤：低 / 中 / 高
```

教学关中区域特征固定。自由模式可以轻微随机初始病毒位置、流体速度和免疫响应延迟。

## 7. 玩家策略

首版保留三种主动策略：

```text
聚集
扩增
隐匿
```

策略作用于当前选中的组织区域。

玩家不是点击单个病毒，而是修改整个区域内病毒群体的行为参数。

### 7.1 聚集

功能：

- 提高病毒在当前区域的局部滞留。
- 减少病毒沿流体通道离开当前区域的比例。
- 提高局部病毒密度。
- 提高局部感染机会。

视觉反馈：

- 病毒粒子逐渐向已有感染热点靠拢。
- 病毒粒子局部密度增加。
- 暖色感染区域变得更集中。
- 病毒不会从远处瞬移过来。
- 不显示吸铁石、箭头或魔法漩涡。

代价：

- 病毒更容易被集中发现。
- 免疫细胞进入后，可能一次清除较多局部病毒。
- 局部炎症和组织损伤可能快速增加。

关键定义：

> 聚集只影响当前区域内病毒的局部滞留和集中，不直接从其他区域抽取病毒。

### 7.2 扩增

功能：

- 提高感染细胞产生新病毒的速度。
- 提高感染区域扩大速度。
- 增加病毒局部数量。

视觉反馈：

- 感染细胞内部暖色颗粒增加。
- 细胞边缘出芽频率提高。
- 新病毒粒子数量增加。
- 感染细胞颜色逐渐由绿色转向琥珀色。

代价：

- 炎症信号快速增加。
- 免疫响应更早到达。
- 细胞死亡和组织损伤更快。
- 可能因为感染过快而失去可感染细胞。

### 7.3 隐匿

功能：

- 降低病毒活动强度。
- 降低病毒被免疫系统发现的概率。
- 降低免疫清除效率。
- 降低病毒移动和复制速度。

视觉反馈：

- 病毒亮度降低。
- 病毒粒子移动变慢。
- 感染区域颜色变暗。
- 免疫信号减少或变弱。

代价：

- 复制速度下降。
- 感染扩散变慢。
- 可能错过快速建立感染的机会。

### 7.4 策略持续和切换

建议使用以下简单限制：

```text
同一时间只能对一个区域施加主动策略。
策略具有持续时间。
策略结束后进入短暂冷却。
玩家可以切换当前控制区域。
```

示例：

```text
策略持续时间：15～25秒
策略冷却时间：5～10秒
```

具体数值由试玩调整。

不建议首版加入复杂资源树或大量技能点。

## 8. 病毒在组织中的运动

### 8.1 微小通道

微小通道是组织背景中低亮度的流体路径。

它们不是：

- 真实水管。
- 具有明确边界的道路。
- 病毒的自动导航路线。
- 玩家可以直接控制的轨道。

通道用于表现病毒和颗粒的大致漂移方向。

### 8.2 漂移实现

每个区域拥有：

```text
fluidDirection
fluidSpeed
```

病毒粒子移动时：

```text
nextPosition =
currentPosition
+ localFluidDirection * fluidSpeed
+ smallRandomOffset
```

效果要求：

- 多数病毒有大致相同的整体漂移方向。
- 单个病毒路径略有差异。
- 病毒可能经过细胞，也可能靠近细胞。
- 病毒不会自动追逐某个细胞。
- 病毒不会全部沿同一条直线移动。

### 8.3 区域间扩散

相邻区域之间通过边界交换病毒。

每个结算周期：

```text
outgoingVirus =
virusLoad
× fluidSpeed
× migrationFactor
× deltaTime
```

实际转移数量受到以下因素影响：

- 当前区域病毒量。
- 流体速度。
- 当前策略。
- 相邻区域状态。
- 少量随机性。

聚集策略降低当前区域流出比例。

隐匿策略降低病毒活动和流出速度。

扩增策略提高病毒总量，间接增加跨区扩散。

## 9. 病毒附着与进入

### 9.1 附着流程

病毒接近细胞时，不一定成功感染。

流程：

```text
病毒接近细胞边缘
→ 检查距离
→ 后台判断是否成功附着
→ 失败：病毒继续漂移或沿膜边缘滑过
→ 成功：病毒停留在细胞膜边缘
→ 播放局部膜亮点
→ 进入感染进程
```

### 9.2 附着判定

可使用简化概率：

```text
attachmentChance =
baseAttachment
× virusAttachmentAbility
× cellSusceptibility
× localVirusDensity
× strategyModifier
× randomFactor
```

需要限制最终概率：

```text
attachmentChance = clamp(attachmentChance, 0, 1)
```

### 9.3 病毒进入

成功附着后：

```text
病毒停留约0.5～1秒
→ 接触点出现短暂亮点
→ 细胞膜局部发生轻微脉冲
→ 病毒粒子淡出或缩小进入细胞
→ 细胞进入早期感染状态
```

进入细胞后，不应立即把整个细胞变成橙色。

建议感染过程分为：

```text
健康
→ 早期感染
→ 活跃感染
→ 受损
→ 死亡或被清除
```

## 10. 病毒复制与释放

### 10.1 感染细胞

感染细胞需要一段时间后才释放新病毒。

```text
感染成功
→ 潜伏延迟
→ 内部暖色颗粒增加
→ 病毒复制强度增加
→ 从细胞边缘出芽释放病毒
```

流感病毒在本游戏中表现为：

> 病毒进入细胞后利用细胞内部资源产生新的病毒颗粒，再从细胞边缘释放。

不要把病毒画成自身像细胞一样分裂。

### 10.2 新病毒量

```text
newVirus =
infectedCellCount
× replicationRate
× strategyModifier
× cellResourceFactor
× deltaTime
```

如果局部健康细胞和资源减少，病毒复制效率应下降。

### 10.3 病毒出芽

视觉流程：

```text
感染细胞膜边缘出现小亮点
→ 小亮点形成小病毒
→ 病毒与膜短暂连接
→ 病毒从膜边缘分离
→ 病毒沿组织通道漂移
```

出芽动画使用固定的短动画或程序缩放，不需要真实模拟膜物理。

## 11. 细胞层数量和布局

### 11.1 推荐数量

一屏细胞层建议包含：

```text
3～5个重点细胞
12～25个低细节细胞轮廓或暗色细胞结构
0～2个重点免疫细胞
若干代表性病毒粒子
```

重点细胞拥有：

- 清楚轮廓。
- 液泡。
- 内部颗粒。
- 感染状态。
- 局部膜动画。

低细节细胞用于补充组织密度，但不需要复杂动画。

### 11.2 为什么不能只有3个细胞

只有少量孤立大细胞会看起来像漂浮的单体，不像组织。

因此画面需要：

- 重点细胞。
- 暗色低细节细胞轮廓。
- 组织纤维。
- 流体通道。
- 稀疏颗粒。

不要用大量细胞铺满画面。组织感来自空间结构，不来自细胞马赛克。

### 11.3 代表性细胞

当前细胞层的细胞是区域状态的代表性可视化，不代表后台只有这些细胞。

例如：

```text
后台：
健康细胞70%
感染细胞20%
死亡细胞10%

画面：
健康重点细胞3个
感染重点细胞1个
受损重点细胞1个
```

当后台发生新感染事件时：

```text
模拟层发出 CellInfected(regionId)
→ 当前细胞层选择一个可见健康细胞
→ 播放病毒附着与进入动画
→ 该细胞转为感染状态
```

如果玩家没有观察该区域，则后台正常计算。玩家之后进入该区域时，根据最新统计状态生成代表性画面。

## 12. 免疫系统

### 12.1 后台核心指标

首版不需要复杂免疫系统，使用：

```text
immunePressure
```

免疫压力由以下因素产生：

```text
infectionLevel
+ inflammation
+ infectedCellCount
+ immuneResponseDelay
```

免疫压力必须有延迟，不应在感染增加的同一帧瞬间达到最大。

### 12.2 免疫细胞表现

免疫细胞只在当前观察区域或附近显示少量代表对象。

建议：

```text
巨噬细胞：0～1个
T细胞：0～1个
```

高免疫压力区域可以同时出现1个巨噬细胞和1个T细胞，但不应触发全屏清除。

### 12.3 巨噬细胞

行为流程：

```text
从区域边缘进入
→ 缓慢移动
→ 接近病毒群或死亡细胞
→ 伸出伪足
→ 清除少量游离病毒或碎片
→ 继续移动
```

巨噬细胞不能一次清除整个区域的病毒。

### 12.4 T细胞

行为流程：

```text
从区域边缘进入
→ 搜索感染细胞
→ 接近目标
→ 在细胞边缘停留
→ 播放接触信号
→ 目标细胞进入被清除或受损状态
→ T细胞离开寻找下一个目标
```

T细胞不能碰到病毒就直接消灭所有病毒。T细胞主要作用于感染细胞。

### 12.5 免疫系统的局部性

免疫压力应影响当前区域及相邻区域，但不能立即影响整个地图。

```text
localImmuneEffect =
immunePressure
× distanceFalloff
```

距离越远，免疫影响越弱。

## 13. 组织损伤

组织损伤来源：

```text
病毒直接损伤
+ 感染细胞死亡
+ 免疫反应造成的局部损伤
```

组织损伤表现：

- 背景纤维变暗。
- 局部通道变得紊乱。
- 细胞边缘变暗或断裂。
- 出现少量细胞碎片。
- 暖色和暗紫色区域增加。
- 组织活动颗粒减少。

不要使用：

- 血液。
- 伤口。
- 爆炸。
- 大面积恐怖腐烂。
- 全屏闪烁。

病毒减少后，组织损伤不会立即恢复。组织修复需要单独的恢复过程。

## 14. 小鼠状态计算

小鼠病情由以下因素共同决定：

```text
viralLoad
inflammation
tissueDamage
respiration
hydration
foodIntake
```

可以使用简化公式：

```text
symptomSeverity =
0.30 * normalizedViralLoad
+ 0.30 * normalizedInflammation
+ 0.40 * normalizedTissueDamage
```

这只是游戏平衡参数，不代表真实医学权重。

### 病毒载量

由所有区域的病毒量加权得到：

```text
globalViralLoad =
sum(region.virusLoad * region.weight)
```

### 炎症

由所有区域炎症水平累积：

```text
globalInflammation =
sum(region.inflammation * region.weight)
```

### 组织损伤

由所有区域组织损伤累积：

```text
globalTissueDamage =
sum(region.tissueDamage * region.weight)
```

### 症状反馈

| 症状等级 | 表现 |
|---|---|
| 低 | 活动略降，轻微鼻部变化 |
| 中 | 活动明显下降，呼吸加快 |
| 高 | 低伏、呼吸困难、进食减少 |
| 极高 | 极少活动，健康值快速下降 |

### 康复判定

```text
if globalViralLoad < recoveryVirusThreshold
and globalTissueDamage < lethalDamageThreshold
and stableTime >= recoveryStableTime:
    outcome = RECOVERED
```

康复应有延迟。

### 死亡判定

```text
if globalTissueDamage >= lethalDamageThreshold:
    outcome = DEAD

if respiration <= minimumRespiration:
    outcome = DEAD

if health <= 0:
    outcome = DEAD
```

## 15. 模拟更新顺序

建议每0.5秒进行一次病程结算。

视觉动画仍然以每秒60帧播放。

每次模拟更新：

```text
1. 应用当前区域策略。
2. 计算病毒在区域内的漂移与滞留。
3. 计算相邻区域之间的病毒扩散。
4. 计算病毒对健康细胞的感染。
5. 更新感染细胞状态。
6. 计算感染细胞释放的新病毒。
7. 更新炎症水平。
8. 更新免疫压力和免疫到达延迟。
9. 计算免疫清除。
10. 更新死亡细胞和组织损伤。
11. 更新全局小鼠状态。
12. 生成表现层事件。
13. 检查康复或死亡。
```

建议模拟层和表现层分离：

```text
SimulationModel
→ 产生状态和事件

PresentationLayer
→ 读取状态
→ 播放粒子、动画和颜色变化

UI
→ 显示状态、按钮和提示
```

## 17. 表现层要求

### 17.1 细胞膜流动

第一版不做真实细胞膜物理模拟。

采用：

```text
固定细胞主体
+ 膜边缘缓慢移动亮点
+ 接触位置局部脉冲
+ 感染区域暖色遮罩
+ 少量内部颗粒移动
```

健康状态：

- 边缘低幅度流动。
- 内部颗粒缓慢运动。
- 亮度变化很小。

病毒接触：

- 接触点短暂变亮。
- 局部膜边缘轻微脉冲。
- 成功进入后病毒粒子淡出。

感染状态：

- 局部颜色从绿色转向琥珀色。
- 内部暖色颗粒增加。
- 边缘活动略微增强。

受损状态：

- 局部边缘变暗。
- 轮廓轻微不稳定。
- 少量碎片脱落。

### 17.2 动画实现方式

推荐使用混合方案：

```text
固定美术素材
+ 程序控制透明度
+ 程序控制颜色
+ 程序控制粒子移动
+ 少量固定短动画
```

不建议每帧重新绘制整张细胞图片。

推荐比例：

```text
约80%动态效果由程序驱动
约20%使用固定短动画
```

### 17.3 固定动画适用范围

适合使用固定短动画：

- 病毒附着闪光。
- 病毒进入。
- 病毒出芽。
- 巨噬细胞吞噬。
- T细胞接触。
- 小鼠鼻部变化。
- 小鼠呼吸循环。

## 19. 一局示例

### 阶段一：初始感染

A区域拥有少量病毒：

```text
virusLoad：低
immunePressure：低
tissueDamage：低
```

玩家观察细胞层，看到病毒缓慢漂移并偶尔接近健康细胞。

### 阶段二：玩家使用扩增

玩家在A区域使用扩增：

```text
感染细胞复制速度提高
→ 病毒颗粒增加
→ 新感染增加
→ 暖色区域扩大
```

小鼠开始出现轻微症状。

### 阶段三：免疫响应出现

A区域感染持续增加：

```text
炎症增加
→ 免疫压力延迟上升
→ 冷色信号出现
→ 巨噬细胞或T细胞进入
```

玩家发现A区域病毒很多，但免疫压力也很高。

### 阶段四：玩家转向B或C区域

玩家进入组织层：

```text
A区：病毒高，免疫高
B区：流体强，病毒容易流失
C区：健康细胞多，免疫低
D区：免疫压力高
```

玩家可以选择：

- 继续扩增A区，尝试快速突破。
- 在B区聚集，减少病毒流失。
- 等待病毒自然进入C区后建立新感染。
- 在D区使用隐匿，降低免疫发现。

### 阶段五：涌现结果

可能出现：

#### 结果A：局部爆发后被清除

```text
A区扩增过快
→ 感染快速增加
→ 免疫集中进入
→ 大量病毒被清除
→ 小鼠逐渐康复
```

#### 结果B：多点感染

```text
玩家使用隐匿
→ 症状出现较慢
→ 病毒沿通道分散
→ B区和C区相继出现小感染点
→ 免疫无法同时快速处理所有区域
→ 小鼠病情恶化
```

#### 结果C：病毒量下降但仍然死亡

```text
病毒被免疫系统压制
→ 病毒载量下降
→ 但组织损伤已过高
→ 呼吸功能持续下降
→ 小鼠无法恢复
```

这三种结果不应由固定剧情触发，而应由模拟状态自然产生。

## 23. 开发验收标准

### 核心玩法

- 玩家能选择区域并使用三种策略。
- 三种策略的收益和代价不同。
- 玩家不能通过一直按同一个按钮稳定获得最佳结果。
- 不同操作顺序可以产生不同结局。

### 涌现表现

- 病毒会从局部感染自然扩散。
- 感染会自然产生炎症。
- 免疫响应具有延迟。
- 免疫响应会局部清除病毒。
- 病毒量下降后组织损伤不会立即消失。
- 小鼠症状由多个因素共同产生。

### 跨尺度一致性

- 组织层显示的感染区域与细胞层一致。
- 细胞层发生的关键事件会影响组织层数据。
- 组织层状态会影响小鼠个体层。
- 滚轮切换不会重置模拟状态。
- 返回上层后可以认出原来的区域。

### 视觉可读性

- 组织层不是培养皿或横切面。
- 细胞层是正俯视2D微观环境。
- 细胞数量不挤满画面。
- 画面中有重点细胞，也有低细节细胞补充组织感。
- 病毒明显小于细胞。
- 免疫细胞不会出现后立即清空病毒。
- 关键动画由模拟事件触发。
