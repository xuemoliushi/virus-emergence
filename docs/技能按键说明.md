# 技能操作更新（2026-10-12）

| 按键 | 功能 |
|---|---|
| E | 基础瞬时吸附；3秒模拟时间冷却，全群共享。 |
| Shift | 获得紧急冲刺后，沿最近主动移动方向立即冲刺；无方向时提示原因。 |
| F | 获得脱落诱饵后立即投入4颗，至少保留3颗；18秒冷却。 |
| V | 打开／关闭功能菜单，模拟继续运行。 |
| 1—6 | 仅在V菜单打开时选择对应功能，主菜单按获得顺序编号。 |
| Esc | 取消菜单或目标选择，不扣质量、不启动技能冷却。 |
| 空格 | 分裂，沿用12病毒门槛、成本、容量和冷却。 |
| Tab | 循环切群，并取消旧菜单、目标选择和群命令。 |

数字2不再绑定基础玩法动作，Q不绑定离散回收。离散回收在V菜单内：选择后启动6秒远距牵引，18秒冷却；不会扩大真实吸收条件。E是原有近距离瞬时吸附，两者冷却独立。E在合法群上空放也算一次发动；冷却期间拒绝请求，不再产生脉冲。暂停冻结冷却，切群无法绕过，重开清理；被动近距吸收不受E冷却影响。

冲刺、诱饵使用专属快捷键及屏幕按钮，不占数字菜单位置；被动卡自动运行，状态显示在本局能力栏。其余已获功能进入V菜单：开关和回收直接执行；目标类显示合法范围，点击合法对象立即执行；非法目标提示原因并保留选择。寄居藏身子菜单分别列出当前群进入及每个隐藏群的退出按钮；全群藏身时仍能打开菜单退出。集群调度子菜单提供集合／留守。

HUD常驻按键说明，按钮及菜单显示成本、冷却、持续时间和开关状态；选卡后的警戒说明同时提示操作方式。目标选择绑定本局和群ID，Tab、控制群死亡、成功分裂、观察、暂停、失焦、结算及重开均取消选择。立即技能成功也取消旧目标；失败保留旧目标且不消耗资源。鼠标、触摸与键盘共用执行入口，键盘重复事件忽略，正式选卡弹窗屏蔽玩法输入。
