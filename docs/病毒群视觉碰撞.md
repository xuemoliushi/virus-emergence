# 病毒群视觉碰撞与漂动

2026-10-17。本轮实现只改变表现副本，玩法坐标、感染/伤害判定、数量账本、输入、模拟随机数与事件保持原协议。

## 表现

- 每个真实病毒记录对应一个表现粒子，不按质量额外补造病毒。聚集个体彼此排斥，受到指向控制圆心的较弱拉力；超出群半径后加强回聚。
- 每个个体具有固定但不同的个人间距，配合低频连续漂动，避免规则晶格。间距附加值每个个体为 0.003–0.021 米；两个个体之间合计约 0.006–0.042 米。
- 病毒与细胞、病毒与免疫细胞、免疫细胞与细胞、免疫细胞之间均有表现碰撞。细胞保留原位，免疫细胞的表现偏移不回写其目标或移动数据。
- 细胞碰撞复用 CellSurface 的离线膜轮廓及细胞旋转，以径向插值近似可见边界，不把逻辑圆半径直接当成可见细胞膜。
- 接触保留切向运动，产生轻微旋转；阻尼及角速度上限防止持续自转或弹飞。
- 分裂、合并保留仍存活个体的表现身份；隐藏、移除、吸收、世界切换及销毁会清理副本。暂停不推进漂动时钟。

已有附着/出芽特效保持各自生命周期；本轮没有改写感染附着记录或把视觉接触当成实际感染。

## 接入与性能边界

`scripts/Game/SwarmVisualPhysics.lua` 持有独立的位置、速度、角度与局部噪声参数。`GameScene.Update` 通过 `CellView.Update` 推进表现；绘制及免疫警示统一读取表现位置。`DrawWorld` 不推进运动。

性能措施：静态细胞空间索引、动态局部分桶、屏外休眠、桶数组复用、每个个体每轮最多访问 48 个邻居、拥挤时降低求解轮数、每帧最多 4 个子步。极端拥挤优先保证计算有界，可能短暂出现少量软重叠。共享波形每个子步只计算四次，个体漂动只做系数组合，不逐帧取随机数。

`Core.PerformanceStats` 新增 `visualPhysicsCPU` 指标，仍使用原有 opt-in 开关。

独立 Lua 5.4 压力测试（固定 1/60 秒步长、单一密集群、90 次采样，排除 GPU/贴图上传/完整游戏）：

| 病毒数 | 中位耗时 | P95 | 最后一步粒子对检查数 |
|---|---:|---:|---:|
| 30 | 0.306 ms | 0.455 ms | 705 |
| 300 | 2.343 ms | 2.542 ms | 6,135 |
| 1000 | 7.819 ms | 9.496 ms | 23,820 |

这组数据不等于 Windows、Web 或手机实机 FPS。尤其 1000 个可见个体仍有明显计算成本，完整游戏的持续帧率与 GC 尖峰需在目标设备继续验收。
