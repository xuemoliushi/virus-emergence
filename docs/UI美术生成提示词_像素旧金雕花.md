# UI 美术生成提示词：像素质感＋旧金色雕花框

2026-10-13 · 用户已确认风格。最新结局方向：鸟只在结局视频中出现，不制作鸟静态图、鸟头像或宿主选择 UI。

## 直接使用方式

下方每个代码块都是完整提示词，可单独复制给图片生成 AI，无需再拼接“总提示词”。每次生成一个素材；后续状态使用文末的图像编辑提示词。建议给 AI 同时附上一张现有卡牌作风格参考，让不同批次保持同一套雕花、像素密度和颜色。

优先参考：[集群调度卡牌](<C:/Users/admin/Documents/病毒模拟/assets/image/card/集群调度.png>)、[贴膜滑行卡牌](<C:/Users/admin/Documents/病毒模拟/assets/image/card/贴膜滑行.png>)。它们的暗紫底、旧金卷叶框与红橙生物插画是本次依据；平滑荧光 B 概念图不作为本次 UI 参考。

推荐色值是从现有视觉提炼的制作配色，不是对源图逐像素采样的结果。菜单／卡牌可保留较完整雕花，HUD 只保留细框和四角装饰，让场景与数据易读。

文字、快捷键、群编号、数量、成本、冷却和进度由游戏叠加；AI 只画底框、图标及装饰。标题也保留程序文字，避免生成文字错误。图标和底框分开导出，便于动态更新和复用。现有九张卡牌插画保留，空白卡框用于统一后续素材，不需要重画整套卡图。

画布尺寸是制作目标，优先保证比例与留白；使用支持透明输出的模型导出带 Alpha 的 PNG，棋盘格图片不能作为透明素材。所有名称均为建议素材文件名，尚未生成图片或接入换皮。
