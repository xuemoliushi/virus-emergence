# 病毒涌现：开始界面

开始界面复用现有组织底纹与细胞拆层，采用近黑紫色背景、暖琥珀强调色和缓慢漂移的病毒微粒。菜单按以下六行排列：病毒涌现、剧情模式、无尽模式、设定、制作名单、退出。

- 剧情模式：接入原有小鼠观察、肺部起点选择与细胞玩法。游戏中 Esc 优先取消技能选择或功能菜单，随后按 Esc 返回开始菜单并暂停病程，再次进入剧情恢复当前进度。
- 无尽模式：禁用，并标注“暂未开放”。
- 设定：主音量、音乐、音效、环境音、语音音量；85% / 100% / 115% 界面缩放；30 / 60 / 120 FPS 上限；开始界面动态背景开关；恢复默认。音量调整即时生效，拖动结束及返回时保存。
- 分辨率：显示当前实际分辨率，随窗口大小更新。引擎禁止 `graphics:SetMode()`，因此未提供无效的分辨率切换按钮。
- 制作名单：黑底滚动占位名单，任意非重复按键或点击返回；滚完自动返回。正式署名填写 `scripts/UI/CreditsData.lua`。
- 退出：调用 `engine:Exit()`；关闭窗口也保留正常退出行为。

主菜单支持上下键选择、Enter / Space 确认，自动跳过不可用的无尽模式。设定界面按 Esc 返回。

设定保存在引擎项目/用户隔离存储的 `virus-emergence-settings.json`，不改写 Maker 项目配置。Web 内存文件系统刷新后可能不保留设置，遵循引擎本地存储限制。

## 音频

- `assets/audio/menu_click.wav`：原样导入桌面“按键.wav”，用于菜单按钮、键盘选择/确认/返回，以及设定调整完成时的反馈；禁用的无尽模式不播放。
- `assets/audio/menu_theme.wav`：原样导入桌面“开始音乐.wav”，在开始菜单、设定和制作名单循环播放，子界面切换不重启音乐。
- 进入剧情切换为原有 `audio/bgm.mp3`，返回开始菜单切回菜单音乐。共用一个音乐声源，切换时停止旧曲。
- 音效归入 `SOUND_EFFECT`，配乐归入 `SOUND_MUSIC`；分别受音效、音乐和主音量设置控制。退出时释放音频场景。
