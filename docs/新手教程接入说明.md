# 新手教程接入说明

2026-10-14。教程直接接在现有「开始」进入剧情的黑屏转场后，沿用当前游戏场景、细胞和病毒美术。

## 玩家流程

1. 介绍玩家控制的病毒群，暂停并聚焦当前玩家。
2. 镜头介绍附近真实健康细胞，再交回控制，引导移动到膜边、保持接触并完成一次实际感染。
3. 等待被感染细胞自然释放病毒。保持原有潜伏 28 秒、后续批次间隔 18 秒；等待期间允许移动和继续感染。
4. 屏幕边缘显示琥珀色三角与「收集病毒 · 距离」文字，指向当前仍可收集的真实病毒。提示出现后，玩家通过靠近或 E／吸附按钮收集病毒。
5. 完成一次真实分裂，再完成一次真实切群。操作失败、只有一群时的切换不计成功；若切群前重新合并，返回分裂提示。
6. 分别聚焦现有 T 细胞与巨噬细胞，解释威胁，点击继续；无需 T 细胞杀死第一枚感染细胞。
7. 交回镜头与控制，玩家实际移动一段距离后介绍左上任务区和进化卡。点击「开始探索」结束教程。

教程前段暂缓免疫细胞行动与招募，介绍免疫细胞后恢复；不会插入强制击杀，也不会改变细胞感染／产毒时间。教程期间正常累计任务事实，选卡界面延后到教程结束再出现。

## 首次进入与设置

- 首次教程开始时即保存已进入标记。退出后重新开始不会自动重复；返回同一局则继续当前步骤。
- 设定页「跳过新手教程」可以跳过教程；进行中的教程也会在恢复游戏时退出。
- 「重置教程」清除已进入标记，并自动取消跳过勾选。下一次开始或继续游戏会重新播放，不清除当前局玩法进度。
- 音量／显示的恢复默认值保留教程状态，教程重播由专用按钮控制。

## 界面与实现位置

沿用紫色／琥珀色界面与实际游戏素材，用聚焦镜头、呼吸光圈、方向三角、八段进度提示和继续按钮组织流程。文本和交互使用 `urhox-libs/UI`，矢量控件只绘制聚焦和方向标记；复用现有字体和渲染管线。

- `scripts/Core/Tutorial.lua`：真实事件驱动的步骤、暂停与操作门控。
- `scripts/UI/TutorialOverlay.lua`：提示卡、场景聚焦标记、边缘方向与文字。
- `scripts/Core/UserSettings.lua`、`scripts/UI/MainMenu.lua`：持久化与设置入口。
- `scripts/main.lua`、`scripts/Game/GameScene.lua`：剧情开头接入、镜头、输入和重播。
- `scripts/Core/SimState.lua`、`scripts/Core/SwarmWorld.lua`：实际动作事件、吸收和免疫时机。
