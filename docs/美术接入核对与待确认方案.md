## 本轮修复

- `scripts/Core/SwarmWorld.lua`：真实释放时记录细胞当时的旋转，使后续旋转仍保持释放提示的局部膜锚点。只新增视觉记录，病毒实际出生时间、数量、位置和 RNG 不变。
- `scripts/Core/CellDiagnostics.lua`：诊断日志改为群体贡献不封顶、仅游离病毒总贡献封顶，匹配现有感染结算；未写回模拟。
- `tests/`：修复 Windows 中文项目路径下 Lua 测试读取失败及硬编码工作路径；新增上述修复的回归用例。

未发现需要本轮重新实现的吸附去重、裁剪、真实感染转换逻辑；这些已在现有游戏链路中。
