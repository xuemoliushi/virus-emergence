# 宿主鸟叫暗示

四版音频是本地程序合成的鸟鸣风格短音，不是录音。Maker 的 batch_sound_effects 返回 INSUFFICIENT_BALANCE，未返回音频结果，也未重复调用。生成脚本为 `tests/generate_bird_hints.py`，输出为 48 kHz、16 位单声道 PCM WAV；参数和 SHA-256 记录在 `validation/bird-hints-20261020/assets.json`。

| 文件 | 试听方向 | 时长 |
| --- | --- | --- |
| bird_hint_soft_pair.wav | 轻啾短句 | 2.1 秒 |
| bird_hint_low_chirp.wav | 低柔啾鸣 | 2.3 秒 |
| bird_hint_tiny_trill.wav | 细碎颤鸣 | 2.4 秒 |
| bird_hint_distant_answer.wav | 远处轻应 | 3.1 秒 |

音频位于 `assets/audio/bird_hints/`，资源路径从 `audio/` 开始。独立的 `Core.BirdAmbience` 声源跟随音乐音量，与底乐叠加，底乐本身不被剪辑或重启。参数集中在 `Config.BirdHints`：

- 教程结束后的安静游玩累计约 41～61 秒首次播放（约 40～60 秒，包含安静缓冲）。
- 四版随机选择；有多个可用版本时不连续重复。每次在当前阶段的音量区间内随机变化，遵循音乐音量设置。
- 阶段 1～2：素材音量 8%～12%，播完后随机等待 80～130 秒。
- 阶段 3～4：素材音量 14%～18%，播完后随机等待 65～110 秒。
- 阶段 5～6：素材音量 22%～28%，播完后随机等待 50～90 秒。
- 阶段推进时音量上下限以每秒 1.5 个百分点平滑接近新目标；正在播放的鸟叫也平滑变化。现有等待计时保留，不因阶段切换重抽或立即播放；播完才按当时阶段抽取下一次等待。
- 暂停、教程、旁白、追逐及追逐淡出时不新发；被打断的短音淡出，恢复安静后留 6 秒缓冲。
- 菜单和加载阶段不播放，换局清理等待状态；胜利／失败开始后不再调度，正在播放的鸟叫加入现有结局淡出。
- 采用独立 Park–Miller 随机流，不消费全局 math.random 或模拟随机数；帧停顿不补播积压短音。
- 资源不可用时保留游戏正常运行，每 10 秒最多重试一轮，恢复后不集中补发。

回归包括素材格式／削波、稀疏随机间隔、版本去重、暂停／旁白／追逐避让、菜单／加载／结局／换局清理、缺失资源恢复、原采样率、音乐分类及模拟 RNG 隔离。播放接口以既有引擎边界夹具验证，未重新打开本机窗口或验证实际设备听感；四版原文件可独立试听。
