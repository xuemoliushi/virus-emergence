# 《涌现》音乐与声音制作要求

## 要 Opus 完成什么

根据 90 秒时间轴创作一条原创纯器乐配乐，并和画面、字幕同步。本包没有现成音频；本文件是执行任务，不是已经交付的音乐。用户目前无视频/音乐生成服务，不以额外购买服务作为默认前提。

Opus 先检查自己的代码执行和导出能力：可用浏览器时采用 Web Audio 的 `OfflineAudioContext`，可执行 Python 时可用数值波形合成并写 WAV。有现成合法音源库可用时提升乐器质感，保留来源说明；没有时明确标为“程序合成配乐”，不声称是真实管风琴或管弦乐录音。只有文字聊天能力时交付乐曲结构与可运行渲染源码，明确音频文件尚未生成。

## 创作语言

管风琴式和声为核心，深沉持续低音、缓慢层叠的弦乐式铺底和克制重复音型。内部脉搏约 64 BPM，允许 60–68 BPM；镜头和旁白服从绝对秒数，不强行卡到节拍。旋律、节奏主题、和声进程与编配原创，不复制任何电影原曲。情绪是辽阔、不可逆、敬畏；死亡段观察而克制，避免煽情悲歌和预告片鼓点。

使用一个简短的原创动机贯穿，第一次扩张与最终释放使用同一材料但不同音域/层数。可从四音动机开始，前段低音区稀疏，城市段扩展音域，地球段首次充分解决；具体音高由 Opus 创作并记录。配器建议：

- Organ：用基音与少量整数泛音叠加，缓起缓收，轻微音色变化；低/中/高音区可分轨，不让高频尖锐刺耳。
- Strings/Pad：多振荡器轻微失谐，低通与慢包络形成弦乐式铺底，避免把锯齿波直接堆响。
- Bass/Drone：稳定低音，但保留能被小扬声器听见的中低频谐波，不只依赖超低频。
- Motif：少量清晰重复音符，群体段积累，死亡时撤走，城市段返回，片尾停止。

这是可行合成思路，不能保证真实管弦乐音色；最终效果须试听。

## 绝对时间与画面联动

| 时间 | 配乐与声音动作 | 对应画面及验收 |
|---|---|---|
| 0–2s | 保留黑屏与画面淡入空间；约 2s 才进入极弱低频 | 不用开场轰鸣吓人 |
| 2–6s | 窄音域持续音，几乎无拍点 | 微观未知感 |
| 6–13s | 管风琴低声部慢慢展开，和声悬而未决 | 拉远揭示宿主，先不提前高潮 |
| 约 13.3–15s | 鸟形约 13s 可认出后延迟 0.3–0.5s 扩大音域 | 第一峰值明显，但低于片尾 |
| 18–34s | 加入原创音型与中声部，稳定推进 | 两群鸟局部转向 |
| 34–36s | 轻积累，保留余量 | 主角最后一次主动振翅 |
| 36–37s | 约 0.6–1s 快速抽掉音型和大多数上层，留低音尾音/弱风声 | 不是整条声轨硬切到零；形成缺口 |
| 37–53s | 稀薄声部，给死亡旁白和坠落留空间 | 无持续悲壮高潮 |
| 53–59s | 管风琴低位重启，环境声从风转城市 | 云后路口建立 |
| 59–76s | 音型回归，逐层加入弦乐和较宽和声 | 城市升高，有推进但不抢旁白 |
| 76–79.5s | 延续上升并保留最后和声悬念 | 城市成为大陆上的一点 |
| 79.5–80.5s | 短暂收薄音色与织体 | 地球揭晓前的呼吸 |
| 81–85.5s | 地球可认出后约 0.3s 开始最宽和声释放 | 可识别节点随实际画面微调，峰值靠近末句结束 |
| 85.5–90s | 撤音型、保留宽尾音，结束前平滑归零 | 标题淡入与留白，无突然截断 |

`timeline.json` 提供这些节点的秒数；固定时点是排期目标。若鸟或地球的实际识别时刻有小幅变化，应同步调整音乐 cue，不改 90 秒总长。

## 环境声与旁白

环境声可用低强度程序噪声滤波形成风、轻微空气脉动和城市底噪；脚步/车轮如无可用声音不要用大音量随机噪声冒充。每种声音单独轨，使用淡入淡出避免接缝。鸟翼只在近景可闻，远景退去；城市声随相机升高减弱，地球段环境声退场。

英语旁白另轨，成熟到年长的低沉纪录片男声，105–115 词/分钟，自然呼吸、克制。旁白文本见 `03_字幕与旁白执行说明.md`。有合法 TTS 工具时先提供候选试听，由用户选择；没有 TTS 时保留可接入的人声轨，先完成配乐和字幕动画，不伪称已有人声，不强制用户先配音才继续工作。

## 同步与导出

1. 音频、画面、字幕用 `timeline.json` 中同一主时间，不各自用独立计时器累积。
2. Web Audio 须在用户点击播放后启动音频上下文；提供实际音量控制。暂停/seek 时停止旧声源，按目标偏移重建播放，禁止旧 BGM 继续在后台叠加。离线导出使用同一配乐事件表，不实时录屏猜同步。
3. 90 秒、48kHz、立体声，样本总数每声道 4,320,000；中间计算可浮点。交付 WAV，16/24-bit PCM 或有说明的浮点格式。提供采样率、位深、时长与复现方法。
4. 配乐建议输出 `audio/ending_emergence_music.wav`；能取得时附 organ、strings、bass、motif 分轨，所有轨从 t=0 开始、同长 90 秒。环境声、旁白独立文件。
5. 人声出现时配乐适度下降，特别避开低中频冲突；保留两次揭晓的动态层次。最终混音可参考约 -14 LUFS、真峰值不高于 -1 dBTP；必须通过真实仪表测量才可声称达到。没有测量工具时只报告实际可测峰值并预留余量，不能把采样峰值当真峰值。
6. 实际试听开场、13 秒、36 秒、53 秒、81–90 秒；同时检查手机/小音箱可懂度、削波、点击声和尾音。不得仅因为脚本写出文件就宣布音乐验收完成。

最终状态要分开写清：配乐是否实际生成、是否能播放、是否完成试听，英文旁白是否存在，最终合成是否导出。无旁白时也可以交付带配乐和双语字幕的动画，标明“旁白待接入”。
